Information Theory & Statistics — Study Module

Oct 11, 2026 · Precious Prince

Twenty lessons that take you from "what is a bit" to maximum likelihood, Fisher information, EM, maximum entropy and information-based hypothesis testing — each built from first principles, worked by hand, and pinned to the exact pages of Kullback (1959) and Dębowski (2013).

How to use this module

Work the lessons in order: each one uses only what came before. Every lesson has the same five parts — Read (exact book pages), Build it (the idea derived from scratch), Worked examples (numbers you can check by hand), Must-know results (statement, meaning, proof idea), and Check yourself (with answers at the end of the lesson).

The two books

  • K = Solomon Kullback, Information Theory and Statistics (Wiley 1959 / Dover 1968). Scanned PDF. PDF page = printed page + 13 (printed p.1 is PDF p.14; printed p.155 is PDF p.168). Uses natural logs. Its main object is I(1:2), the mean information for discriminating hypothesis H1 from H2.
  • D = Łukasz Dębowski, Information Theory and Statistics (IPI PAN, Warsaw 2013). Text PDF. PDF page = printed page. Uses log base 2.

Part A — Measuring information

Lesson 1 — Surprise and entropy ★★★

Entropy is the average number of yes/no questions needed to learn an outcome; it is forced on us by one requirement — information from independent events must add.

Read

  • D ch.2, pp.15–17: Def. 2.3 (entropy, p.16), Example 2.2 (p.16), Fig. 1 binary entropy curve and Thm 2.2 (p.17), Defs 2.4–2.5 (p.17). Note the sentence on p.16: "we postulate H(X,Y) = H(X) + H(Y)… Because log(xy) = log x + log y… the following definition comes as a very natural idea."
  • K ch.1 §4, pp.7–8 (PDF 20–21): Example 4.1 (information of verifying a hypothesis = −log P(H1)), Example 4.2, eq. (4.1) entropy of hypotheses, the definition of a bit, Hartley's measure log n, and the units "Hartley" (base 10) and "nit" (base e).

Build it

Step 1 — the question game. I pick one of N equally likely options; you find it with yes/no questions. Each balanced question halves the candidates, so you need log₂ N questions: 2 options → 1, 4 → 2, 8 → 3. This is Hartley's measure (K p.7).

Step 2 — surprise of one outcome. An outcome with probability p behaves like "one of 1/p equal options", so its information is log₂(1/p). Three requirements force the log:

  1. Rarer → more surprising (decreasing in p).
  2. Certain → no information: p = 1 gives 0.
  3. Independent events add: probabilities multiply (p·q), so we need s(p·q) = s(p) + s(q).

The only continuous decreasing function with property 3 is s(p) = −c·log p; the constant c just picks the unit (bits for base 2, nats for base e).

\[s(x) = -\log P(X = x)\]

Step 3 — entropy = expected surprise. Before seeing the outcome, weight each outcome's surprise by how often it occurs. D writes this compactly as H(X) = E[−log P(X)] (Def. 2.3, p.16), where P(X) is itself a random variable (Def. 2.1, p.15).

\[H(X) = \mathbb{E}\left[-\log P(X)\right] = -\sum_{x:\,P(X=x)>0} P(X=x)\,\log P(X=x)\]

The convention 0·log 0 = 0 (outcomes that never happen contribute nothing) is why the sum runs over p(x) > 0.

Step 4 — additivity check. For independent X, Y: −log P(X,Y) = −log P(X) − log P(Y), and expectations add (D Thm 2.1, p.16), so H(X,Y) = H(X) + H(Y). This is the property we built the definition to satisfy.

Worked examples

Distribution Calculation H (bits)
Fair coin (½, ½) ½·1 + ½·1 1
D Example 2.2: (1/3, 2/3) log 3 − 2/3 0.918
Biased coin (0.9, 0.1) 0.9·0.152 + 0.1·3.322 0.469
K Problem 5.1(a): (0.99, 0.01) 0.99·0.0145 + 0.01·6.644 0.081

The match-result example shows what entropy means operationally. Ask "home win?" first; if no, ask "draw?". Average questions = ½·1 + ½·2 = 1.5 = H. Entropy equals the best achievable average number of questions — Lesson 6 proves this in general (source coding theorem).

The biased coin shows why the average is low even though one outcome is very surprising. The rare side carries 3.3 bits but appears 10% of the time; the common side carries 0.15 bits. A predictable source carries little information per observation.

Must-know results

  1. Non-negativity (D Thm 2.2, p.17). H(X) ≥ 0, with equality only if X takes a single value. Reason: each term −p log p ≥ 0 for p ∈ (0, 1], and is 0 only at p = 1.
  2. Maximum at uniform (D Thm 2.5, p.19; K Example 3.1, eq. (3.6), pp.16–17). If X takes n values, H(X) ≤ log n, with equality only for the uniform distribution. Proof needs KL divergence — Lesson 2.
  3. Entropy depends only on the probabilities, not the labels. (1/3, 2/3) and (2/3, 1/3) have the same entropy (D p.16). Relabelling or permuting outcomes changes nothing.
  4. Binary entropy function h(p) = −p log p − (1−p) log(1−p): symmetric about ½, peaks at 1 bit, zero at p = 0 and 1 (D Fig. 1, p.17). You will see h(p) inside Fano's inequality (Lesson 5).

Units. log₂ → bits; ln → nats (K calls them "nits", p.8); log₁₀ → hartleys. 1 nat = 1/ln 2 ≈ 1.443 bits. Kullback and PyTorch use nats; D uses bits.

Where it shows up

  • LLMs: per-token loss in nats; perplexity = e^(loss in nats) = 2^(loss in bits) — the effective number of equally likely next tokens (Lesson 7).
  • Decision trees: split quality = drop in label entropy (information gain, Lesson 4).
  • Uncertainty and active learning: the entropy of a softmax output flags inputs the model is unsure about.
  • Reinforcement learning: an entropy bonus on the policy keeps it exploring (SAC, PPO).
  • Feature cardinality: a column with entropy near 0 is almost constant — useless as a feature.

Traps

  • Entropy is a property of a distribution, not of one observed value. "The entropy of 7" is meaningless; the surprise of 7 is not.
  • H(X) can be infinite for variables with infinitely many values (D Remark after Thm 2.5, p.19; ex. 15, p.24).
  • Changing the log base rescales every entropy by the same constant; it never changes which distribution has more entropy.

Lesson 2 — KL divergence: information for discrimination ★★★

KL divergence is the average weight of evidence one observation gives for the true hypothesis over a wrong one; it is never negative, and zero only when the two distributions are the same.

Read

  • K ch.1 §2, pp.3–5 (PDF 16–18): Bayes in log-odds form, eqs. (2.2)–(2.3); the definition of information for discrimination log[f1(x)/f2(x)] and its mean I(1:2), eqs. (2.4)–(2.5).
  • K ch.1 §3, pp.6–7 (PDF 19–20): I(2:1) and the divergence J(1,2), eq. (3.2); why J is not a distance.
  • K ch.2 §2, pp.12–14 (PDF 25–27): Thm 2.1 additivity for independent observations; Thm 2.2 conditional additivity; Example 2.1 (bivariate normal).
  • K ch.2 §3, pp.14–18 (PDF 27–31): Thm 3.1 I(1:2) ≥ 0, with the Taylor-expansion proof (3.1)–(3.5).
  • K ch.2 §5, pp.22–26 (PDF 35–39): the same properties for J (Thms 5.1–5.5).
  • D ch.2, pp.17–19: Def. 2.6 (KL), Def. 2.7 (convexity), Example 2.3, Thm 2.3 (Jensen), Thm 2.4 (D ≥ 0), Thm 2.5 (max entropy proof).
  • K Problems 5.2, 5.6, 5.7 (pp.10–11). Table II at the back (p.378) tabulates the binary KL F(p1,p2).

Build it

Step 1 — evidence is a log-likelihood ratio. Two hypotheses: H1 (data come from f1) and H2 (data come from f2). Bayes' rule (K eq. 2.2, p.4) gives the posterior odds after seeing x:

\[\frac{P(H_1\mid x)}{P(H_2\mid x)} = \frac{f_1(x)}{f_2(x)}\cdot\frac{P(H_1)}{P(H_2)}\]

Take logs and the multiplication becomes addition (K eq. 2.3, p.4):

\[\log\frac{f_1(x)}{f_2(x)} = \log\frac{P(H_1\mid x)}{P(H_2\mid x)} - \log\frac{P(H_1)}{P(H_2)}\]

The left side is how far the observation moved your log-odds. Kullback defines it as "the information in X = x for discrimination in favor of H1 against H2" (p.5); I. J. Good called it the weight of evidence. It can be negative: some observations point the wrong way.

Step 2 — average it. If H1 is actually true, x is drawn from f1. The expected evidence per observation is (K eq. 2.5, p.5):

\[I(1{:}2) = \int f_1(x)\,\log\frac{f_1(x)}{f_2(x)}\,d\lambda(x) \;=\; D(f_1\,\|\,f_2)\]

For discrete distributions, D writes D(p‖q) = Σ p(x) log[p(x)/q(x)] (Def. 2.6, p.18). Same object.

Step 3 — the reverse direction and the symmetric version. I(2:1) = D(f2‖f1) is the expected evidence for H2 when H2 is true (K eq. 3.1, p.6). Kullback's divergence adds the two (K eq. 3.2, p.6):

\[J(1,2) = I(1{:}2) + I(2{:}1) = \int \big(f_1(x)-f_2(x)\big)\log\frac{f_1(x)}{f_2(x)}\,d\lambda(x)\]

J is symmetric and measures "the difficulty of discriminating" between the hypotheses, but it fails the triangle inequality, so it is not a metric (K p.6).

Step 4 — why it can never be negative (Jensen). A function f is convex if the chord lies above the curve: Σ pᵢ f(xᵢ) ≥ f(Σ pᵢ xᵢ) (D Def. 2.7 and Thm 2.3, p.18). −log is strictly convex (positive second derivative, D Example 2.3). Apply Jensen with f = −log to the ratio q/p (D Thm 2.4 proof, p.19):

\[D(p\|q) = \sum_x p(x)\left(-\log\frac{q(x)}{p(x)}\right) \;\ge\; -\log\sum_x p(x)\frac{q(x)}{p(x)} = -\log\sum_{x:p(x)>0} q(x) \;\ge\; -\log 1 = 0\]

Equality needs the ratio q/p to be constant (Jensen's equality case) and the q-mass to sit only where p > 0, so p = q. This result is sometimes called Gibbs' inequality. Kullback proves the same thing differently: write g = f1/f2, Taylor-expand φ(t) = t log t around 1, and use φ''(t) = 1/t > 0 (K eqs. 3.1–3.5, p.15).

Step 5 — payoff: uniform maximises entropy (D Thm 2.5, p.19). Let q be uniform on n values. Then D(p‖q) = Σ p log(p·n) = log n − H(p) ≥ 0, so H(p) ≤ log n, with equality only for p = q. K gets the same result as Example 3.1, eq. (3.6), p.16.

Worked examples

Spam filter (one observation). The word "free" appears in 30% of spam and 1% of normal mail. Evidence for spam = log₂(0.30/0.01) = log₂ 30 = 4.91 bits. If prior odds spam:ham = 1:4, posterior odds = 30 × ¼ = 7.5:1, so P(spam | "free") = 7.5/8.5 = 0.88. Evidence adds: a second independent word worth 2 bits multiplies the odds by another 4.

Two coins, both directions. p = (0.5, 0.5) fair, q = (0.9, 0.1) biased.

Quantity Calculation Bits
D(p‖q) 0.5·log(0.5/0.9) + 0.5·log(0.5/0.1) 0.737
D(q‖p) 0.9·log(0.9/0.5) + 0.1·log(0.1/0.5) 0.531
J sum of the two 1.268

The two directions differ. If the coin is really fair, you collect evidence faster (0.737 bits per toss) than if it is really biased (0.531), because fair-coin tails are very unlikely under the biased coin.

Two normals with equal variance (K Problem 5.2(d), p.10). fᵢ = N(μᵢ, σ²). The log-ratio is [(x−μ₂)² − (x−μ₁)²]/(2σ²). Under f1, E[(x−μ₂)²] = σ² + (μ₁−μ₂)² and E[(x−μ₁)²] = σ², so

\[I(1{:}2) = \frac{(\mu_1-\mu_2)^2}{2\sigma^2}\ \text{nats}, \qquad J(1,2) = \frac{(\mu_1-\mu_2)^2}{\sigma^2}\]

The information is the squared separation in standard-deviation units — the same quantity that drives a z-test and LDA (Lesson 19).

When KL is infinite. p = (0.5, 0.5), q = (1, 0). D(p‖q) contains 0.5·log(0.5/0) = ∞: one tail proves q wrong forever. D(q‖p) = log 2 = 1 bit is finite. This is why K assumes the measures are mutually absolutely continuous (p.3) and why K Problem 5.7 builds a pair with I(1:2) = ∞ but I(2:1) < ∞.

Must-know results

  1. D(p‖q) ≥ 0, equality iff p = q (D Thm 2.4, p.18; K Thm 3.1, p.14). Everything else in Part A is derived from this.
  2. Not symmetric: D(p‖q) ≠ D(q‖p) in general. Use J (K eq. 3.2) when you need symmetry.
  3. Additivity for independent observations (K Thm 2.1, p.12): I(1:2; X, Y) = I(1:2; X) + I(1:2; Y). So n i.i.d. observations give n·I(1:2) — evidence grows linearly with sample size, which is why tests get more powerful with more data (Lesson 17).
  4. Chain rule (K Thm 2.2, p.13): I(1:2; X, Y) = I(1:2; X) + I(1:2; Y | X).
  5. Jensen's inequality (D Thm 2.3, p.18): for convex f, E[f(X)] ≥ f(E[X]). You will reuse it in EM (Lesson 15) and in every variational bound.

Where it shows up

  • VAEs: the loss has a KL(q(z|x) ‖ N(0, I)) term (closed form in Lesson 9).
  • RLHF / fine-tuning: a KL penalty keeps the tuned policy close to the reference model.
  • Knowledge distillation: match student to teacher by minimising KL between their softmax outputs.
  • Drift monitoring: the Population Stability Index, Σ (aᵢ − eᵢ) ln(aᵢ/eᵢ), is exactly Kullback's J (eq. 3.2) on binned data.
  • Bayesian updating: log-odds plus evidence (eq. 2.3) is the logic behind naive Bayes and logistic regression's additive log-odds.

Traps

  • KL is not a distance: no symmetry, no triangle inequality.
  • Zeros matter: q(x) = 0 where p(x) > 0 makes D(p‖q) infinite. In practice, smooth or clip probabilities.
  • The direction matters for optimisation (forward vs reverse KL — Lesson 3).

Lesson 3 — Cross-entropy: the loss you already use ★★★

Cross-entropy is the average surprise when reality follows p but you predict with q; it equals H(p) + D(p‖q), so minimising it over q is the same as minimising KL to the truth.

Read

  • D Def. 2.6, p.18: D(p‖q) = −Σ p log q − H(p). Rearranged, that is cross-entropy = H(p) + D(p‖q).
  • D ch.12 ex. 7, p.115: names the quantity, H(ρ‖σ) := −∫ ρ ln σ = H(ρ) + D(ρ‖σ). (D writes cross-entropy with a double bar; most ML texts write H(p, q).)
  • D ch.2 ex. 14, p.24: P(X = X̂) ≥ 2^(−H(p) − D(p‖r)) — the chance a guess drawn from r hits X is bounded by 2 to the minus cross-entropy.
  • D ch.11, p.102: the EM objective Q is "a difference of the likelihood and a cross entropy function" (preview of Lesson 15).
  • Neither book makes cross-entropy a headline; this lesson is the bridge from the books' KL to the losses you train with.

Build it

Step 1 — surprise under the wrong model. Outcomes happen with true frequencies p, but your model assigns probabilities q. Each outcome x costs you −log q(x) bits of surprise. Averaging over what actually happens:

\[H(p, q) = -\sum_x p(x)\log q(x)\]

Step 2 — split it. Add and subtract log p(x) inside the sum:

\[H(p,q) = \underbrace{-\sum_x p(x)\log p(x)}_{H(p)} \;+\; \underbrace{\sum_x p(x)\log\frac{p(x)}{q(x)}}_{D(p\|q)}\]

H(p) is the irreducible uncertainty in the data. D(p‖q) is the extra cost of using the wrong model. Because D ≥ 0 (Lesson 2), H(p, q) ≥ H(p), with equality only at q = p.

Step 3 — why this is the training loss. For a dataset (x₁, y₁), …, (x_N, y_N), the usual classification loss is the average of −log q(yᵢ | xᵢ). That is the cross-entropy between the empirical label distribution and the model. The data's H(p) does not depend on the model, so gradient descent on cross-entropy is gradient descent on KL(data ‖ model). Lesson 12 shows this is exactly maximum likelihood.

Step 4 — one-hot labels. If the true label is class c with certainty, p is one-hot, H(p) = 0, and the loss collapses to −log q(c): only the probability given to the correct class matters.

Step 5 — forward vs reverse KL. When q cannot match p exactly (say p has two peaks and q is a single Gaussian), the direction you minimise decides the compromise.

Objective Penalises Result Used in
Forward: min over q of D(p‖q) q ≈ 0 where p > 0 (infinite cost) q spreads to cover every mode ("mode-covering") MLE, cross-entropy training, distillation
Reverse: min over q of D(q‖p) q > 0 where p ≈ 0 q locks onto one mode ("mode-seeking") variational inference, VAEs' posterior, some RL policy updates

The reason is in the zeros (Lesson 2's infinite-KL example): the distribution in front of the log is the one whose support must be respected.

Must-know results

  1. H(p, q) = H(p) + D(p‖q) ≥ H(p) (D Def. 2.6 rearranged; D ch.12 ex. 7). Minimising cross-entropy over q = minimising forward KL.
  2. Cross-entropy is a proper scoring rule. The expected log-loss is minimised only by reporting the true probabilities. That is why log-loss rewards calibration, and accuracy does not.
  3. Binary case = logistic loss: −[y log σ(z) + (1−y) log(1−σ(z))].
  4. Bits per token and perplexity: average −log₂ q(next token) over a corpus is the model's cross-entropy rate; perplexity = 2^that (Lesson 7).

Where it shows up

  • nn.CrossEntropyLoss (PyTorch) takes logits, applies log-softmax, and returns mean −ln q(y) in nats.
  • LLM pre-training loss, and "compression = prediction" (Lesson 6: a model with cross-entropy H bits/token compresses text to about H bits/token).
  • Calibration metrics (log-loss), probabilistic forecasting (e.g. match-outcome models are scored with log-loss or the related ranked probability score).

Traps

  • Cross-entropy is not symmetric and not a divergence: H(p, p) = H(p) ≠ 0.
  • Training loss in nats vs a paper reporting bits: divide nats by ln 2 = 0.693 to get bits.
  • A small loss does not mean the task is easy; compare against H(p) when you can estimate it, and against the ln K baseline.

Lesson 4 — Joint and conditional entropy, chain rule, mutual information ★★★

Mutual information is how much knowing Y cuts your uncertainty about X; it is the KL divergence between the joint distribution and the "independent" version of it, so it is zero exactly when X and Y are independent.

Read

  • D ch.2, pp.19–23: Def. 2.8 conditional entropy (p.19); Thm 2.6 H(X|Y) = 0 iff X is a function of Y (p.19); Example 2.4 (p.20); Thm 2.7 H(X|Y) = E[−log P(X|Y)] (p.20); Def. 2.9 and Thm 2.8 mutual information (pp.20–21); eq. (2.2) (p.21); Defs 2.10–2.11 and Thms 2.9–2.12 (pp.21–23).
  • D exercises pp.23–25: ex. 5 (H(X|Y)+H(Y|X) is a metric), ex. 6 (Venn diagrams, Figs. 2–3, and triple information), ex. 11 (chain rule), ex. 12.
  • K ch.1 Example 4.3, p.8 (PDF 21): mean information in x about y, eq. (4.2), and its value for a bivariate normal, eq. (4.3) = −½ log(1 − ρ²). Example 4.5, pp.8–9: the channel-capacity formula ½ log(1 + S/N), eq. (4.8).
  • K ch.2 Thm 2.2, p.13 (chain rule for I(1:2)) and Corollary 3.3, p.18 (the joint carries at least as much discrimination information as any part).

Build it

Step 1 — joint entropy. A pair (X, Y) is just one random variable with more values: H(X, Y) = E[−log P(X, Y)].

Step 2 — conditional entropy. If you learn Y = y, the leftover uncertainty about X is H(X | Y = y), the entropy of the conditional distribution. Average over y (D Def. 2.8, p.19):

\[H(X\mid Y) = \sum_y P(Y=y)\,H(X\mid Y=y) = \mathbb{E}\left[-\log P(X\mid Y)\right]\]

The second form is D Thm 2.7 (p.20).

Step 3 — the chain rule. Since P(X, Y) = P(Y)·P(X | Y), taking −log and expectations gives:

\[H(X,Y) = H(Y) + H(X\mid Y), \qquad H(X_1,\dots,X_n) = \sum_{i=1}^{n} H(X_i\mid X_1,\dots,X_{i-1})\]

In words: total uncertainty = uncertainty about the first thing + uncertainty about the second given the first. The n-variable version is D ex. 11 (p.25). It is exactly how an autoregressive language model factorises a sentence.

Step 4 — mutual information as KL. Compare the true joint P(X, Y) with what it would be if X and Y were independent, P(X)P(Y). The KL between them (D Def. 2.9, p.20; K eq. 4.2, p.8):

\[I(X;Y) = \mathbb{E}\left[\log\frac{P(X,Y)}{P(X)P(Y)}\right] = D\big(P_{XY}\,\big\|\,P_X P_Y\big)\]

In Kullback's language: H1 = "x and y are dependent with density f(x, y)", H2 = "they are independent, g(x)h(y)"; I(1:2) is the mean information for detecting the dependence (K p.8).

Step 5 — the identities. Expanding the log ratio gives (D eq. 2.2, p.21; Thm 2.12, p.23):

\[I(X;Y) = H(X) - H(X\mid Y) = H(Y) - H(Y\mid X) = H(X) + H(Y) - H(X,Y)\]

Picture two overlapping circles (D ex. 6, Fig. 2): each circle is H(X) or H(Y), the overlap is I(X;Y), the union is H(X, Y), and the parts outside the overlap are H(X|Y) and H(Y|X).

Step 6 — conditional mutual information. I(X;Y | Z) = E[log P(X,Y|Z)/(P(X|Z)P(Y|Z))] (D Def. 2.10, Thm 2.9, p.21). It is zero iff X and Y are conditionally independent given Z (Thm 2.10, p.22). Chain rule for information (Thm 2.11, p.23):

\[I(X;Y,Z) = I(X;Z) + I(X;Y\mid Z)\]

Rain and umbrellas. R = it rains, U = someone carries an umbrella.

Seeing umbrellas removes 0.276 of the 0.811 bits of uncertainty about rain — about a third. That number is the information gain a decision tree would compute for splitting "rain" on "umbrella".

One event can increase uncertainty; the average cannot (D Example 2.4, p.20). H(X) = 0.811, but given a particular event A, H(X|A) = 1 > H(X). On average over all values of Y, H(X|Y) ≤ H(X) always (D p.21). "Information never hurts on average" — not "every observation reduces uncertainty".

Gaussian mutual information (K eq. 4.3, p.8). For a bivariate normal with correlation ρ, I = −½ log(1 − ρ²). With ρ = 0.5: −½ log₂ 0.75 = 0.208 bits. As |ρ| → 1 it goes to ∞; at ρ = 0 it is 0. For Gaussians, correlation and MI carry the same information; for non-Gaussian data, MI also catches non-linear dependence that correlation misses.

Conditioning can create dependence (XOR). X, Y independent fair bits, Z = X XOR Y. Then I(X;Y) = 0 but I(X;Y | Z) = 1 bit: once you know Z, Y tells you X exactly. So D's triple information I(X;Y;Z) = I(X;Y) − I(X;Y|Z) = −1 can be negative (D ex. 6). This is the information-theoretic face of "collider bias" in causal inference.

Must-know results

  1. I(X;Y) ≥ 0, equality iff independent (D Thm 2.8, p.21) — because it is a KL.
  2. Conditioning reduces entropy on average: H(X|Y) ≤ H(X) (D p.21); and subadditivity: H(X, Y) ≤ H(X) + H(Y).
  3. H(X|Y) = 0 iff X = f(Y) (D Thm 2.6, p.19): zero leftover uncertainty means X is determined by Y.
  4. Chain rules for entropy (D ex. 11) and information (D Thm 2.11; K Thm 2.2).
  5. I(X;X) = H(X) (D p.20): entropy is self-information.

Where it shows up

  • Feature selection: rank features by I(feature; target) (scikit-learn mutual_info_classif); mRMR adds a redundancy penalty using I(feature; feature).
  • Decision trees: ID3/C4.5 choose the split with the largest information gain = I(Y; split).
  • Representation learning: InfoNCE (contrastive learning, CLIP) maximises a lower bound on I(view₁; view₂); the information bottleneck trades I(X;Z) against I(Z;Y).
  • Autoregressive models: the chain rule is the factorisation p(x₁…xₙ) = ∏ p(xᵢ | x₁…xᵢ₋₁).
  • Clustering evaluation: normalised mutual information (NMI) between predicted clusters and labels.

Traps

  • MI is symmetric, I(X;Y) = I(Y;X); conditional entropy is not.
  • Estimating MI for continuous variables from samples is hard (binning bias, k-NN estimators); the formula is easy, the estimate is not.
  • I(X;Y|Z) can be larger or smaller than I(X;Y) — there is no general inequality between them.

Lesson 5 — Data processing, invariance and Fano ★★★

No processing of data can create information about the thing you care about; it can only keep it (if the processing is sufficient or invertible) or lose it — and the information left sets a hard floor on any classifier's error.

Read

  • K ch.2 §3, Corollaries 3.1–3.2 and Examples 3.2–3.4, pp.15–18 (PDF 28–31): grouping observations loses information, with equality exactly when the conditional density within each group is the same under both hypotheses.
  • K ch.2 §4, pp.18–22 (PDF 31–35): Thm 4.1 I(1:2; X) ≥ I(1:2; Y) for any statistic Y = T(X), with the equality condition (4.5); Thm 4.2 (equality iff T is sufficient); Corollary 4.1 (no loss under a one-to-one transformation). The summary paragraph on p.22: "There can be no gain of information by statistical processing of data."
  • D ch.2 exercises, pp.23–25: ex. 4 H(g(X)) ≤ H(X); ex. 8 data-processing inequality; ex. 9 I(X; g(Y)) ≤ I(X; Y); ex. 10 Markov chains; ex. 13 Fano's inequality. Def. 2.12 and Example 2.7 (p.22) for Markov chains.

Build it

Step 1 — a Markov chain X → Y → Z. Z is computed from Y alone (plus independent noise, if any), so once you know Y, Z tells you nothing more about X: X and Z are conditionally independent given Y (D Def. 2.11, Example 2.5, p.22). Typical cases: X = true label, Y = raw image, Z = extracted features. Or X = parameter θ, Y = sample, Z = a statistic.

Step 2 — the data-processing inequality (D ex. 8). Use the chain rule for information (Lesson 4) two ways:

\[I(X;Y,Z) = I(X;Y) + I(X;Z\mid Y) = I(X;Z) + I(X;Y\mid Z)\]

The Markov property makes I(X;Z | Y) = 0. So I(X;Y) = I(X;Z) + I(X;Y | Z) ≥ I(X;Z):

\[X \to Y \to Z \quad\Longrightarrow\quad I(X;Z) \le I(X;Y)\]

Step 3 — Kullback's version: discrimination information. Replace "information about X" with "evidence for H1 against H2". For any statistic Y = T(X) (K Thm 4.1, p.19):

\[I(1{:}2;\mathcal{X}) \;\ge\; I(1{:}2;\mathcal{Y}), \quad \text{equality iff } \frac{f_1(x)}{f_2(x)} = \frac{g_1(T(x))}{g_2(T(x))}\ [\lambda]\]

The equality condition (4.5) says: the likelihood ratio depends on x only through T(x). Equivalently, the conditional distribution of x given T(x) is the same under both hypotheses — T is sufficient (Thm 4.2, p.21; Lesson 10).

Step 4 — grouping is a special case (K Corollary 3.2, p.16). Binning the sample space into cells E₁, E₂, … and recording only the cell:

\[I(1{:}2) \;\ge\; \sum_i \mu_1(E_i)\log\frac{\mu_1(E_i)}{\mu_2(E_i)}\]

Kullback's comment (p.16): "the grouping of observations generally causes a loss of information." On p.22 he adds that averaging and looking only at marginals also lose information in general.

Step 5 — invariance (K Corollary 4.1, p.21). If T is one-to-one ("nonsingular"), you can undo it, so apply the inequality both ways: I(1:2; X) = I(1:2; T(X)). Information does not care about units, log transforms or any invertible reparametrisation. The same holds for mutual information: I(f(X); g(Y)) = I(X; Y) for invertible f, g.

Step 6 — Fano's inequality: information limits accuracy (D ex. 13, p.25). You predict X with X̂ = g(Y). Let pₑ = P(X̂ ≠ X). To know X after the guess, you need to know whether the guess was wrong (at most h(pₑ) bits) and, if wrong, which of the other values it was (at most log|𝒳| bits, used with probability pₑ):

\[h(p_e) + p_e\log|\mathcal{X}| \;\ge\; H(X\mid \hat X) \;\ge\; H(X\mid Y)\]

Since h(pₑ) ≤ 1 bit, a usable form is pₑ ≥ (H(X|Y) − 1)/log₂|𝒳|.

Worked examples

Binning loses evidence. Three categories with p₁ = (0.5, 0.3, 0.2) under H1 and p₂ = (0.2, 0.3, 0.5) under H2. Merge categories 2 and 3 into one bin.

All 3 categories (0.5, 0.3, 0.2) (0.2, 0.3, 0.5) 0.397
Merged 2+3 (0.5, 0.5) (0.2, 0.8) 0.322

About 19% of the evidence per observation is lost. The loss would be zero only if, inside the merged bin, the split between categories 2 and 3 were the same under both hypotheses (here it is 0.3:0.2 vs 0.3:0.5, so it is not).

Fano in practice. A 10-class problem where your features leave H(X|Y) = 2 bits of uncertainty about the label. Any classifier, however deep, has error ≥ (2 − 1)/log₂ 10 = 0.30. If you need 10% error, you need better data, not a better model.

Invariance in practice. Log-transforming income changes its correlation with spending, but not its mutual information with spending. Correlation is a property of the representation; MI is a property of the information.

Must-know results

  1. Data-processing inequality: X → Y → Z ⇒ I(X;Z) ≤ I(X;Y) (D ex. 8); in particular I(X; g(Y)) ≤ I(X; Y) (D ex. 9) and H(g(X)) ≤ H(X) (D ex. 4).
  2. Information loss under statistics: I(1:2; T(X)) ≤ I(1:2; X), equality iff T is sufficient (K Thms 4.1–4.2). This is the information-theoretic definition of sufficiency.
  3. Invariance under one-to-one maps (K Cor. 4.1).
  4. Fano's inequality (D ex. 13): small conditional entropy is necessary for small error.
  5. For a Markov chain, information between variables decays with distance: I(Xᵢ; Xₖ) ≤ I(Xᵢ; Xⱼ) for i ≤ j ≤ k (D ex. 10).

Where it shows up

  • Feature engineering cannot add information about the target that the raw data lack. What it can do is make existing information usable by a limited model (a linear model cannot compute x² by itself). DPI is about information, not about what a given model can extract.
  • Deep networks: each layer is a function of the previous one, so I(layer; label) can only fall as you go deeper — the starting point of the information-bottleneck view of deep learning.
  • Aggregation in analytics: reporting only weekly totals, or bucketing ages, throws away evidence (K Cor. 3.2); decide this consciously.
  • Normalizing flows use invertible maps precisely so that no information is lost.
  • Bayes error / label noise: Fano gives a lower bound on achievable error from H(label | features).

Traps

  • DPI needs the Markov structure. If Z uses information not in Y (another data source), the inequality does not apply.
  • "No information gain" does not mean "no accuracy gain" for a fixed, limited model class.
  • Equality in DPI is special (sufficiency); expect strict loss by default.

Part B — Compression is prediction

Lesson 6 — Codes, Kraft inequality, source coding theorem ★★★

No lossless code can beat H(X) bits per symbol on average, and a code built from lengths ⌈−log p(x)⌉ gets within 1 bit of it — so every code is secretly a probability model, and a better model means a shorter code.

Read

  • D ch.3, pp.27–38. Defs 3.1–3.5 and Thms 3.1–3.2 (codes, unique decodability, comma and fixed-length codes, pp.27–28); Example 3.5 (p.29); Thm 3.3 Kraft inequality (p.29, McMillan's proof); Thm 3.4 source coding inequality (p.30, proof via KL); Defs 3.6–3.7 prefix-free codes and Thm 3.5 (pp.30–31); Thm 3.6 converse of Kraft (p.31); Def. 3.9 and Thm 3.7 Shannon–Fano codes (p.32); Example 3.11 (p.33); code trees, Thm 3.8 (pp.33–34); Def. 3.14 Huffman code and Example 3.14 (pp.34–35); Thm 3.9 Huffman optimality (p.36).
  • D exercises pp.37–38: ex. 1 (which codes are prefix-free), ex. 3 (D-ary codes), ex. 5 (build Huffman codes), ex. 7 (two different Huffman codes), ex. 8 (dyadic distributions), ex. 9 (Elias omega code).
  • K touches this only in passing: Problem 8.36 (p.35) notes the link between a maximum-entropy problem and "the noiseless coding theorem".

Build it

Step 1 — what a code is. A code maps each symbol to a binary string. It must be decodable when code words are glued together. {a→0, b→1, c→10} fails: "10" could be "ba" or "c" (D Example 3.2). A prefix-free code (no code word starts another) can be decoded left to right with no look-ahead, and is always uniquely decodable (D Thm 3.5).

Step 2 — short words are a scarce resource (Kraft). Think of the binary tree of all strings. A code word of length l uses up a fraction 2⁻ˡ of the tree below it, and prefix-free words cannot overlap. So the fractions must fit in 1:

\[\sum_{x} 2^{-|B(x)|} \le 1\]

D Thm 3.3 proves this holds for every uniquely decodable code, not only prefix-free ones. Thm 3.6 gives the converse: any lengths satisfying Kraft can be realised by a prefix-free code. So you lose nothing by restricting to prefix-free codes.

Step 3 — a code is a probability distribution. Kraft says r(x) = 2^(−length(x)) is (at most) a probability distribution. A code that gives x a short word is "betting" that x is likely.

Step 4 — the source coding theorem (D Thm 3.4, p.30). Let p be the true distribution and r(x) = 2^(−|B(x)|) / Σ_y 2^(−|B(y)|) the normalised code distribution. D's proof shows:

\[\mathbb{E}|B(X)| - H(X) = D(p\,\|\,r) - \log\sum_x 2^{-|B(x)|} \;\ge\; 0\]

Both terms are ≥ 0 (KL is non-negative; Kraft makes the log term ≤ 0). So expected length ≥ entropy, and the waste is exactly the KL between the truth and the distribution your code assumes. Read that twice: code-length overhead = model error measured in KL.

Step 5 — achieving it (Shannon–Fano, D Thm 3.7, p.32). Choose lengths ⌈−log p(x)⌉. They satisfy Kraft, so a prefix-free code with these lengths exists, and

\[H(X) \le \mathbb{E}|B(X)| < H(X) + 1\]

The +1 is rounding to whole bits. Coding blocks of n symbols at once spreads it out to 1/n per symbol (used in Lesson 7).

Step 6 — the best code (Huffman, D Def. 3.14 and Thm 3.9). Repeatedly merge the two least likely nodes into one; read the code words off the resulting tree. This minimises expected length among all symbol codes. Proof idea (p.36): the two rarest symbols can always be put as siblings at the deepest level; merge them and recurse.

Must-know results

  1. Kraft inequality (D Thm 3.3) and its converse (Thm 3.6).
  2. Source coding theorem (D Thm 3.4 + Thm 3.7): H ≤ optimal expected length < H + 1.
  3. Huffman optimality for symbol-by-symbol codes (D Thm 3.9).
  4. Ideal code length = −log p(x), and coding with the wrong distribution r costs H(p) + D(p‖r) bits on average.
  5. D-ary alphabets: divide by log D (D ex. 3).

Where it shows up

  • LLMs as compressors. Feed a language model's next-token probabilities into an arithmetic coder and the file size ≈ the model's total cross-entropy in bits. Lower validation loss literally means better compression — the "prediction = compression" view of language modelling.
  • File formats: Huffman coding inside DEFLATE (zip, gzip, PNG) and JPEG.
  • Minimum description length (MDL) model selection: choose the model that minimises (bits to describe the model) + (bits to describe the data with it), where the second term is −log-likelihood (Lesson 20).
  • Feature hashing / tokenisation: BPE tokenisers effectively assign short units to frequent strings.

Traps

  • "Entropy is the compression limit" holds for lossless coding of a source with known distribution. With unknown distributions you pay extra (universal codes, Lesson 8).
  • Huffman is optimal among symbol codes, not among all schemes; arithmetic coding beats it on skewed sources by not rounding each symbol to whole bits.
  • A fixed-length code is optimal only for uniform distributions.

Lesson 7 — Entropy rate of sequences and perplexity ★★

For a sequence with memory, the right measure is entropy per symbol given the past — the entropy rate h. It is never more than the single-symbol entropy, it is the best achievable compression rate, and a language model's perplexity is 2^(its estimate of h).

Build it

Step 1 — stationarity. A process is stationary if any block of n consecutive symbols has the same distribution wherever it starts (D Def. 4.5). Then the block entropy H(n) = H(X₁, …, Xₙ) depends only on n.

Step 2 — new information per step. By the chain rule (Lesson 4), the extra entropy added by the n-th symbol is (D Thm 4.6):

\[\Delta H(n) = H(n) - H(n-1) = H(X_n \mid X_1,\dots,X_{n-1})\]

Conditioning on more past can only lower this, so ΔH(n) is non-increasing: H(n) grows, but more and more slowly (it is concave).

Step 3 — the limit is the entropy rate (D Def. 4.10, Thm 4.7).

\[h = \lim_{n\to\infty} H(X_n \mid X_1,\dots,X_{n-1}) = \lim_{n\to\infty}\frac{H(X_1,\dots,X_n)}{n}, \qquad 0 \le h \le H(X_1)\]

Two readings of one number: the uncertainty about the next symbol given the entire past, and the average uncertainty per symbol of a long block.

Step 4 — Markov chains (D Example 4.6). If the next symbol depends only on the current one, the past beyond one step adds nothing, so h = H(X₂ | X₁):

\[h = -\sum_{k}\pi_k\sum_{l} p_{kl}\log p_{kl}\]

where π is the stationary distribution (π = πP, D Thm 4.4) and p_kl the transition probabilities.

Step 5 — compression (D Thm 4.8). Shannon–Fano-code whole blocks of n symbols: n·Lₙ lies between H(n) and H(n) + 1, so the best bits per symbol Lₙ → h. Entropy rate is the compression limit for sources with memory.

Worked examples

A two-state weather chain. Sunny stays sunny with probability 0.9; rainy stays rainy with probability 0.5.

Must-know results

  1. ΔH(n) = H(Xₙ | past n−1) is non-increasing; H(n) is concave (D Thm 4.6).
  2. h = lim H(n)/n = lim H(Xₙ | X₁ⁿ⁻¹) (D Def. 4.10, Thm 4.7).
  3. 0 ≤ h ≤ H(X₁), with h = H(X₁) iff the process is i.i.d. (D ex. 5). Memory always helps or does nothing.
  4. Markov entropy rate formula (D Example 4.6).
  5. Entropy rate = optimal compression rate (D Thm 4.8).

Where it shows up

  • Language-model evaluation: perplexity, bits-per-byte (used to compare models with different tokenisers), and scaling-law curves that approach an irreducible loss term — an estimate of the text's entropy rate.
  • Context length: ΔH(n) falling with n is why longer context lowers loss, with diminishing returns (concavity).
  • Time series and event data: entropy rate of a symbolised sequence measures predictability (e.g. how predictable a team's pass sequences or a user's click stream are).
  • HMMs: D Def. 4.7 — the observed process is a function of a hidden Markov chain (speech, tagging, Lesson 15's Baum–Welch).

Traps

  • Perplexities computed with different tokenisers are not comparable; convert to bits per byte or per character first.
  • Measured loss estimates cross-entropy, not h itself; the gap is the model's KL from the truth.
  • Entropy rate needs stationarity. A text whose topic drifts has no single h; that is one reason Lesson 8 adds ergodicity.

Lesson 8 — Ergodicity, typical sequences (AEP) and universal compression ★★

For a well-behaved (stationary ergodic) source, almost every long sequence has probability about 2^(−nh): −(1/n) log P(X₁…Xₙ) converges to the entropy rate. That single fact explains why time averages can be trusted, why compression works without knowing the distribution, and why a model's average log-loss on one long text estimates its true cross-entropy.

Read

  • D ch.5, pp.47–55. Def. 5.2 ergodicity (p.48); Thm 5.1 Birkhoff's ergodic theorem (p.48) — read the statement and the paragraph after it, skip the proof (pp.48–50) on first pass; Example 5.2 a non-ergodic process (p.50); Thm 5.2 when a Markov chain is ergodic (p.51); Examples 5.3–5.4 (p.51); Thm 5.3 functions of ergodic processes are ergodic (p.51); Thm 5.4 Shannon–McMillan–Breiman (p.52); its proof via Lemmas 5.2–5.4 (pp.52–54) is optional.
  • D ch.6, pp.57–61 ★: Defs 6.1–6.2 universal codes (p.57); the remark that a universal code's compression rate is an entropy-rate estimator (p.58); Def. 6.3 Lempel–Ziv code with the parsing example (p.58); Thm 6.2 (p.58). Note D's remark that gzip is not truly universal because of its finite buffer (p.58).

Build it

Step 1 — the problem. You see one long sequence (one season of matches, one corpus), not many independent copies of the process. When does an average along that one sequence equal the true expectation?

Step 2 — ergodicity. A stationary process is ergodic if no event that is unchanged by time-shifts has probability strictly between 0 and 1 (D Def. 5.2). In plain terms: there is no hidden coin flipped once at the start that sends you into one of several different "worlds" forever. D Example 5.2 is exactly that: a variable Z picks process U or W at time 0, and the long-run frequencies then depend on Z — stationary, but not ergodic.

Step 3 — the ergodic theorem (D Thm 5.1). The process is ergodic iff for every integrable function, the time average converges to the expectation with probability 1:

\[\lim_{n\to\infty}\frac{1}{n}\sum_{k=1}^{n} X_k = \mathbb{E}X_0 \quad\text{(almost surely)}\]

The strong law of large numbers is the i.i.d. special case (D Example 5.3). For Markov chains, ergodicity = a unique stationary distribution = no two disjoint closed sets of states (D Thm 5.2).

Step 4 — Shannon–McMillan–Breiman (D Thm 5.4). Apply the ergodic theorem to the "surprise per symbol" −log P(Xₖ | past). The average surprise of the observed sequence converges to the entropy rate:

\[-\frac{1}{n}\log P(X_1,\dots,X_n) \;\xrightarrow{\text{a.s.}}\; h\]

This is the asymptotic equipartition property (AEP): long sequences split into a typical set of about 2^(nh) sequences, each with probability about 2^(−nh), which together carry almost all the probability; everything else is negligible.

Step 5 — universal compression (D ch.6). Shannon–Fano coding of blocks needs the true distribution. Lempel–Ziv does not: parse the sequence into the shortest phrases not seen before, and code each phrase as (index of its longest earlier prefix, one new bit) (D Def. 6.3). For every stationary ergodic source, its bits per symbol → h (Thm 6.2). It learns the statistics as it goes.

Worked examples

Typical sequences of a biased coin. n = 100 tosses, P(1) = 0.1, so h = h(0.1) = 0.469 bits.

Quantity Value
All possible sequences 2^100
Typical set size, about 2^(nh) 2^46.9
Sequences with exactly 10 ones C(100,10) = 1.7×10^13 ≈ 2^44.0
Probability of each of them 0.1^10·0.9^90 = 7.6×10^−15 ≈ 2^−46.9
P(5 to 15 ones) 0.94
Probability of the single most likely sequence (all zeros) 0.9^100 = 2.7×10^−5

The most likely single sequence is not typical: it has far too few ones, and the whole set of such extreme sequences carries tiny probability. Typical sequences are individually unlikely but collectively almost certain. That is why you only need about nh = 47 bits, not 100, to index what will actually happen.

LZ parsing (D p.58). 001010010011100… → phrases 0 | 01 | 010 | 0100 | 1 | 11 | 00 | …, coded as (0,0)(1,1)(10,0)(11,0)(0,1)(101,1)(1,0). A repetitive sequence produces few, long phrases and compresses well; a random one produces many short phrases.

Must-know results

  1. Ergodic theorem (D Thm 5.1): time average = expectation, for stationary ergodic processes.
  2. Shannon–McMillan–Breiman / AEP (D Thm 5.4): −(1/n) log P(X₁ⁿ) → h almost surely.
  3. Typical set: ≈ 2^(nh) sequences of probability ≈ 2^(−nh) each, with total probability → 1.
  4. Universal codes exist (D Thm 6.2): Lempel–Ziv's rate → h without knowing the source; compression ratio is therefore an entropy-rate estimator (D p.58).

Where it shows up

  • Evaluation on one long corpus is meaningful: by the ergodic theorem, average log-loss on a long held-out text converges to the model's true cross-entropy rate — provided the text is "ergodic enough" (no mid-stream regime change).
  • Time-series practice: a single long history can estimate expectations only under stationarity + ergodicity. Regime switches (Example 5.2) break this — relevant for financial and sports data across seasons or rule changes.
  • MCMC: sample averages from a Markov chain estimate posterior expectations because the chain is ergodic (D Thm 5.2 conditions).
  • Compression-based similarity: normalised compression distance (e.g. with gzip) for clustering texts or detecting duplicates; gzip-plus-k-NN text classifiers rely on this.
  • High-dimensional intuition: samples from a high-dimensional Gaussian sit on a thin shell, not near the mode — the continuous version of "the most likely sequence is not typical". It matters for sampling and decoding (why pure greedy/beam decoding gives atypical, repetitive text).

Traps

  • Stationary does not imply ergodic (Example 5.2).
  • "Typical" does not mean "most probable".
  • Practical compressors with finite windows only approximate universality.

Lesson 9 — Continuous variables: differential entropy and Gaussians ★★★

For densities, KL and mutual information carry over unchanged (still ≥ 0, still invariant), but entropy becomes "differential entropy", which can be negative and depends on units. Among all distributions with a given variance the Gaussian has the most entropy, and the KL between two Gaussians has a closed form you will use constantly.

Read

  • D ch.7, pp.63–65, 67: Def. 7.1 differential entropy and Example 7.1 (Gaussian entropy, negative when σ < 1/√(2πe)) (p.63); Def. 7.2 and Thm 7.1 (KL ≥ 0 for densities, proof via ln x ≥ 1 − 1/x) (p.64); mutual information for real variables, eq. Pages 65–69 on Durbin–Levinson and spectral theory are optional ★ (time-series specialists only).
  • K ch.9 §1, pp.189–191: eq. (1.1) log-likelihood ratio of two k-variate normals; eq. (1.2) I(1:2) for multivariate normals; (1.3) J(1,2); (1.4)–(1.5) equal covariances (Mahalanobis distance); (1.6)–(1.7) equal means; (1.8)–(1.11) the univariate cases.
  • K ch.1 Examples 4.3–4.5, pp.8–9: Gaussian mutual information (4.3) and the channel-capacity formula ½ log(1 + S/N), eq. (4.8).
  • K ch.2 Problems 8.14–8.15 (p.32): the normal maximises entropy for fixed variance; Problem 8.26 (p.33): uniform maximises it on a bounded volume; Problem 8.27 (pp.33–34): exponential maximises it for a non-negative variable with fixed mean. D ch.12 ex. 3 and 5 (p.115) are the same facts.

Build it

Step 1 — the naive limit fails. Chop the real line into bins of width Δ. The discrete entropy of the binned variable is about −∫ f ln f − ln Δ, which goes to ∞ as Δ → 0: a real number carries infinitely many bits. Dropping the −ln Δ term defines differential entropy (D Def. 7.1):

\[H(f) = -\int f(x)\ln f(x)\,dx\]

It measures spread on a log scale, not "bits to describe X". It can be negative, and rescaling X by a changes it by ln|a|.

Step 2 — what survives intact. In KL and mutual information, the −ln Δ terms cancel, because they are differences/ratios of densities. So D(f‖g) ≥ 0 with equality iff f = g a.e. (D Thm 7.1), I(X;Y) ≥ 0, and both are invariant to one-to-one transformations (K Cor. 4.1). For continuous data, KL and MI are the trustworthy quantities; differential entropy is a convenience.

Step 3 — the Gaussian's entropy (D Example 7.1). For N(μ, σ²), −ln f(x) = ½ ln(2πσ²) + (x−μ)²/(2σ²). Taking expectations, E(x−μ)² = σ²:

\[H\big(N(\mu,\sigma^2)\big) = \tfrac12\ln(2\pi e\,\sigma^2), \qquad H\big(N(\mu,\Sigma)\big) = \tfrac{k}{2}\ln(2\pi e) + \tfrac12\ln\det\Sigma\]

The multivariate form is D Thm 7.5. ln det Σ is the log-volume of the uncertainty ellipsoid.

Step 4 — the Gaussian maximises entropy for a fixed variance (K Problem 8.14). Let f be any density with variance σ² and φ the normal with the same mean and variance. Since ln φ is a quadratic in x, ∫ f ln φ depends only on f's mean and variance, so it equals ∫ φ ln φ. Then:

\[0 \le D(f\|\varphi) = -H(f) - \int f\ln\varphi = -H(f) + H(\varphi) \;\Longrightarrow\; H(f) \le H(\varphi)\]

This is the template for every maximum-entropy result (Lesson 16): the max-ent distribution is the exponential family whose log-density uses exactly the constrained statistics.

Step 5 — KL between two Gaussians (K ch.9 eq. 1.2, p.189). Take the expectation of the log-ratio (1.1) under f₁:

\[I(1{:}2) = \tfrac12\ln\frac{|\Sigma_2|}{|\Sigma_1|} + \tfrac12\operatorname{tr}\Sigma_1\big(\Sigma_2^{-1}-\Sigma_1^{-1}\big) + \tfrac12(\mu_1-\mu_2)'\Sigma_2^{-1}(\mu_1-\mu_2)\]

Univariate form (combine K eqs 1.8 and 1.10):

\[D\big(N(\mu_1,\sigma_1^2)\,\|\,N(\mu_2,\sigma_2^2)\big) = \ln\frac{\sigma_2}{\sigma_1} + \frac{\sigma_1^2 + (\mu_1-\mu_2)^2}{2\sigma_2^2} - \frac12\]

Kullback notes (p.190) the information splits into a part due to the difference in means ("size") and a part due to the difference in covariances ("shape"). With equal covariances only the mean part survives: I(1:2) = ½ δ'Σ⁻¹δ, half the squared Mahalanobis distance (K eq. 1.4).

Step 6 — Gaussian mutual information (D Thm 7.6; K eq. 4.3). I(X;Y) = H(X) + H(Y) − H(X,Y); the 2πe terms cancel and det Σ = σₓ²σᵧ²(1 − ρ²), so I = −½ ln(1 − ρ²). For signal-plus-noise Y = X + N, ρ² = S/(S+N) and I = ½ ln(1 + S/N), Shannon's channel capacity (K eq. 4.8).

Must-know results

  1. Differential entropy can be negative and is not scale-invariant; KL and MI are ≥ 0 and invariant (D Def. 7.1, Thm 7.1; K Cor. 4.1).
  2. Gaussian entropy ½ ln(2πeσ²), and ½ ln((2πe)^k det Σ) (D Example 7.1, Thm 7.5).
  3. Maximum entropy: normal for fixed variance; uniform on a bounded set; exponential for fixed mean on [0, ∞) (K Problems 8.14, 8.26, 8.27).
  4. KL between Gaussians (K ch.9 eq. 1.2) and its univariate/equal-covariance special cases.
  5. Gaussian MI = −½ ln(1 − ρ²); channel capacity ½ ln(1 + S/N).

Where it shows up

  • VAEs and diffusion models: closed-form Gaussian KL terms in the ELBO.
  • Why Gaussians are the default: if you only trust the mean and variance, the Gaussian is the least-committal (max-entropy) choice; this also justifies squared-error loss as Gaussian log-likelihood.
  • Drift and anomaly detection: Gaussian KL between a reference window and a new window of features; Mahalanobis distance for outliers.
  • Gaussian-process / Bayesian optimisation: information-gain acquisition functions use ½ log det of covariance matrices.
  • Time series: D Thm 7.7 links partial autocorrelation to conditional mutual information — PACF is information about the next value not already explained by the intermediate lags.

Traps

  • Never compare differential entropies across different units (metres vs centimetres differ by ln 100).
  • H(X|Y) can be negative for continuous variables (D p.64); I(X;Y) cannot.
  • Gaussian KL formulas assume full-rank covariances; a near-singular Σ makes the log-det blow up.

Lesson 10 — Sufficient statistics ★★

A statistic is sufficient when compressing the data down to it loses no information about the parameter — the data-processing inequality holds with equality. You find one by factorising the likelihood.

Build it

Step 1 — the question. You have n observations but want to keep only a summary T (a count, a mean). When does the summary lose nothing about the unknown parameter θ?

Step 2 — the definition. T is sufficient if, once you know T, the remaining detail of the sample has a distribution that does not depend on θ (D Def. 8.3). The leftover detail is pure noise as far as θ is concerned.

Step 3 — the information version. Treat θ as random (Bayesian view). Θ → X → T(X) is a Markov chain, so by data processing (Lesson 5) I(T; Θ) ≤ I(X; Θ). D Thm 8.1:

\[T \text{ is sufficient} \iff I\big(T(X_1^n);\Theta\big) = I\big(X_1^n;\Theta\big)\]

Kullback's non-Bayesian version (Thm 4.2): T is sufficient iff it keeps the full discrimination information I(1:2) between every pair of parameter values. Sufficient = lossless compression for the purpose of inference.

Step 4 — the practical test: factorisation (D Thm 8.2). T is sufficient iff the likelihood splits as

\[P(x_1^n\mid\theta) = h(x_1^n)\cdot g\big(\theta, T(x_1^n)\big)\]

The parameter only ever "sees" the data through T. The likelihood ratio between any two θ's is g(θ₁,T)/g(θ₂,T), a function of T alone — exactly Kullback's equality condition (4.5).

Step 5 — minimal sufficiency (D Def. 8.4, Thm 8.3). The most compressed sufficient statistic: T(x) = T(y) exactly when the likelihood ratio P(x|θ)/P(y|θ) does not depend on θ. Two samples are "the same" for inference iff they have proportional likelihood functions.

Must-know results

  1. Sufficiency = no information loss (D Thm 8.1; K Thms 4.1–4.2).
  2. Fisher factorisation theorem (D Thm 8.2): the working test.
  3. Minimal sufficiency via likelihood ratios (D Thm 8.3).
  4. Exponential families have fixed-size sufficient statistics (ΣT(xᵢ)) whatever n is (K ch.3 Thm 3.1; D Thm 8.4, next lesson). For most other families the minimal sufficient statistic grows with n.

Where it shows up

  • Streaming and big data: for exponential-family models you only need running sums (count, Σx, Σx², XᵀX, Xᵀy), not the raw rows — the basis of one-pass and federated estimation.
  • Linear regression with Gaussian noise: (XᵀX, Xᵀy, yᵀy) are sufficient; the whole dataset can be compressed to them without changing the fit.
  • Feature engineering: an aggregate (match totals, weekly sums) is lossless only if it is sufficient for the model you care about; otherwise you are throwing away evidence, measurably (K Example 7.4).
  • Simulation-based inference / ABC: quality depends on how close the chosen summary statistics are to sufficient.
  • Representation learning: the information-bottleneck ideal is a "minimal sufficient statistic" of the input for the label.

Traps

  • Sufficiency is relative to a model. Σxᵢ is sufficient for a Bernoulli model, not for a Markov model of the same tosses (order then matters).
  • "Sufficient" does not mean "good estimator"; it means "nothing lost". You still have to build an estimator from it (Lessons 12–13).
  • The factorisation must hold for all θ and (almost) all samples, including the support condition (uniform and shifted-exponential cases).

Lesson 11 — Exponential families ★★★

An exponential family is a base distribution tilted by exp(θ·T(x)) and renormalised; one function — the log-normaliser A(θ) = ln Z(θ) — gives you the mean (its gradient), the variance and Fisher information (its Hessian), the MLE (match the means), and the KL between members (a Bregman divergence). Softmax, logistic regression and GLMs are all this one idea.

Read

  • D ch.8, pp.75–77: Def. 8.5 exponential family with canonical sum Z(θ) (p.75); Example 8.7 Bernoulli and the logit (pp.75–76); Example 8.8 normal (p.76); Thm 8.4 minimal sufficient statistic ΣT(xᵢ) (p.76); Thm 8.6 completeness (p.77). Exercises pp.78–79: Poisson, geometric, negative binomial, gamma, beta, Pareto, inverse Gauss are all exponential families.
  • D ch.9 exercises pp.89–91: ex. 1 (MLE for an exponential family), ex. 7 (its Fisher information), ex. 8–10 (mean-value parametrisation, Legendre transform, and the one-to-one correspondence between exponential families and Bregman divergences). D ch.2 ex. 19–23 (p.26) define Bregman divergence.
  • K ch.3 §2, eqs (2.6)–(2.11), pp.38–39: the minimum-discrimination solution f*(x) = e^(τT(x)) f₂(x)/M₂(τ) "is said to generate an exponential family" (p.38). Table on p.40 and Example 2.1 (binomial, Table 2.1) on p.41.
  • K ch.3 §4, pp.45–55: Lemmas 4.1–4.3 (derivatives of log M₂(τ) give the mean and variance of T, p.46); Lemmas 4.10–4.12 (the variance matrix is the Fisher information matrix, p.49); Example 4.1 binomial, eqs (4.3)–(4.6) (p.49). K ch.3 Corollary 3.2 (p.45): closed-form I and J between two members.

Build it

Step 1 — the form. Start from a base measure p(x) and a vector of statistics T(x). Tilt by exp(θ·T(x)) and renormalise (D Def. 8.5):

\[P(x\mid\theta) = p(x)\,\exp\big(\theta\cdot T(x) - A(\theta)\big), \qquad A(\theta) = \ln Z(\theta) = \ln\sum_x p(x)\,e^{\theta\cdot T(x)}\]

θ are the natural (canonical) parameters; A is the log-partition function. Kullback writes the same thing as f*(x) = e^(τT(x)) f₂(x)/M₂(τ), with M₂(τ) the moment-generating function of T under f₂ (K eq. 2.11).

Step 2 — recognise the families. Rewrite a familiar density as exp(something linear in the parameter):

Distribution T(x) Natural parameter θ A(θ)
Bernoulli(p) (D Ex. 8.7) x logit: ln(p/(1−p)) ln(1 + e^θ)
Categorical(p₁..p_K) one-hot x logits η_k = ln(p_k/p_K) log-sum-exp of the logits
Poisson(λ) x ln λ e^θ = λ
Normal(μ, σ²) (D Ex. 8.8) (x, x²) (μ/σ², −1/(2σ²)) μ²/(2σ²) + ln(σ√(2π))
Exponential(β) x −β −ln(−θ)

The categorical row is the softmax: p_k = e^(η_k)/Σ_j e^(η_j).

Step 3 — A(θ) generates the moments (K Lemmas 4.1–4.3; D ch.9 ex. 7–8). Differentiate A = ln Σ p(x)e^(θ·T(x)):

\[\nabla A(\theta) = \mathbb{E}_\theta[T(X)], \qquad \nabla^2 A(\theta) = \operatorname{Cov}_\theta[T(X)] = J_1(\theta)\]

The Hessian is a covariance matrix, so A is convex. It is also the Fisher information in the natural parameters (K Lemma 4.10, p.49; Lesson 13).

Step 4 — MLE = moment matching (D ch.9 ex. 1). The log-likelihood of n i.i.d. points is θ·ΣT(xᵢ) − nA(θ) + const. It is concave in θ (since A is convex), so set the gradient to zero:

\[\mathbb{E}_{\hat\theta}[T(X)] = \frac1n\sum_{i=1}^n T(x_i)\]

The fitted model reproduces the sample averages of the sufficient statistics — nothing more, nothing less. The sufficient statistic is ΣT(xᵢ), fixed in size whatever n is (D Thm 8.4).

Step 5 — KL between members is a Bregman divergence (K Cor. 3.2; D ch.9 ex. 8–9). Plug two members into the KL formula; the p(x) cancels and the expectation of T under θ₁ is ∇A(θ₁):

\[D(\theta_1\|\theta_2) = A(\theta_2) - A(\theta_1) - (\theta_2-\theta_1)\cdot\nabla A(\theta_1)\]

That is the gap between the convex function A and its tangent line — the Bregman divergence of A. Squared Euclidean distance is the Bregman divergence of the Gaussian family; KL is the Bregman divergence of negative entropy (D ch.2 ex. 19, ch.9 ex. 9).

Worked examples

Bernoulli through A. A(θ) = ln(1 + e^θ). A'(θ) = e^θ/(1+e^θ) = σ(θ) = p, the sigmoid. A''(θ) = p(1−p) = variance = Fisher information in the logit scale. At p = 0.2: θ = ln(0.25) = −1.386, variance 0.16.

Softmax gradient = moment matching. For one example with one-hot label y and logits η, the cross-entropy loss is A(η) − η·y. Its gradient is ∇A − y = p − y: predicted probabilities minus observed. Training pushes the model's expected T (class probabilities) toward the observed T (labels) — Step 4 in one line. Logistic regression's gradient Xᵀ(p − y) is the same thing.

Poisson MLE. T = x, ∇A = λ. Matching gives λ̂ = x̄ (D ch.9 ex. 2). Variance of T = λ, so Fisher information about λ from n counts is n/λ.

Kullback's binomial (K Example 4.1, eq. 4.6). For n trials, I(1:2) = n[p₁ ln(p₁/p₂) + q₁ ln(q₁/q₂)], and for nearby p₁, p₂ it is ≈ n(p₁ − p₂)²/(2pq): squared difference over twice the variance — the quadratic approximation Lesson 13 makes general.

Must-know results

  1. Canonical form P(x|θ) = p(x)exp(θ·T(x) − A(θ)) (D Def. 8.5; K eq. 2.11).
  2. ∇A = mean of T, ∇²A = covariance of T = Fisher information; A is convex (K Lemmas 4.1–4.3, 4.10).
  3. Sufficient statistic ΣT(xᵢ) of fixed dimension (D Thm 8.4; K ch.3 Thm 3.1).
  4. MLE = moment matching; log-likelihood concave in θ — so fitting is a convex problem with a unique optimum (full-rank case).
  5. KL between members = Bregman divergence of A (K Cor. 3.2; D ch.9 ex. 8–9).
  6. Exponential families are exactly the maximum-entropy distributions under constraints on E[T] (Lesson 16; K ch.3 §2).

Where it shows up

  • Softmax/sigmoid output layers = categorical/Bernoulli exponential families with the network producing the natural parameters.
  • GLMs: linear predictor = natural parameter; link function = inverse of ∇A (logit for Bernoulli, log for Poisson). Poisson regression for counts (goals, events), gamma for durations.
  • Energy-based models and Boltzmann machines: p(x) ∝ exp(−E(x)), with ln Z the hard part.
  • Conjugate priors exist for every exponential family (Lesson 14).
  • Natural gradient / mirror descent: the geometry of A (Fisher metric, Bregman divergences) is the geometry these optimisers use.

Traps

  • The support must not depend on θ — Uniform(0, θ) is not an exponential family.
  • Mean parameters (p, λ, μ) and natural parameters (logit, ln λ, μ/σ²) are different coordinates; formulas for Fisher information change with the coordinates (Lesson 13).
  • Overparametrisation: softmax with K free logits is not full rank (adding a constant to all logits changes nothing). Fix one logit or add regularisation.

Lesson 12 — Maximum likelihood is KL minimisation ★★★

Maximising the average log-likelihood is the same as minimising the KL divergence from the data's distribution to the model. That one identity explains why MLE is consistent, what it converges to when the model is wrong, and why cross-entropy training is MLE.

Read

  • D ch.9, pp.81–85: Def. 9.1 MLE (p.81); Examples 9.1–9.2 Bernoulli and normal MLEs, eq. (9.2) (pp.81–82); Def. 9.2 consistency (p.82); Thm 9.1 consistency for a finite parameter set, proved with KL and the law of large numbers (pp.82–83); Thm 9.2 Wald's theorem for a real parameter (pp.83–84, statement + idea only); Defs 9.3–9.4 bias and MSE (p.84); Thm 9.3 MSE → 0 implies consistency (p.85); Example 9.3 (p.85).
  • D ch.9 exercises pp.89–90: ex. 3 (MSE = variance + bias²), ex. 4 (divisors n−1, n, n+1 for the variance, and which has the smallest MSE), ex. 1–2 (MLE for exponential families and Poisson).
  • K has no chapter on MLE, but K ch.5 §4 (p.94) notes that the parameter estimate inside his statistic Î(*:2) is the maximum-likelihood estimate, and that Î(*:2) is the log of a maximised likelihood ratio, eq. (4.1) — preview of Lesson 17.

Build it

Step 1 — the likelihood. Data x₁, …, xₙ are fixed; view P(x₁…xₙ | θ) as a function of θ. The MLE picks the θ that made the observed data most probable (D Def. 9.1). For i.i.d. data, take logs so the product becomes a sum:

\[\hat\theta_{ML} = \arg\max_\theta \frac1n\sum_{i=1}^n \ln P(x_i\mid\theta)\]

Step 2 — what that average converges to. If the data come from a true distribution p, the law of large numbers turns the average into an expectation:

\[\frac1n\sum_{i=1}^n \ln P(x_i\mid\theta) \;\to\; \mathbb{E}_p[\ln P(X\mid\theta)] = -H(p) - D\big(p\,\|\,P(\cdot\mid\theta)\big)\]

H(p) does not depend on θ. So maximising likelihood ≈ minimising D(p ‖ P_θ). With the empirical distribution p̂ in place of p, the identity is exact: the MLE minimises D(p̂ ‖ P_θ), i.e. the cross-entropy H(p̂, P_θ) (Lesson 3).

Step 3 — consistency (D Thm 9.1). If θ₀ is the truth and θₖ ≠ θ₀, the per-observation log-likelihood ratio averages to D(θ₀‖θₖ) > 0. So, with probability → 1, the true parameter beats every wrong one, and the MLE picks it. KL > 0 between distinct distributions is literally the engine of the proof. Wald's theorem (Thm 9.2) extends this to continuous θ with a compactness argument.

Step 4 — misspecification. If no θ gives the true p, the MLE still converges — to θ* = argmin D(p ‖ P_θ), the KL projection of the truth onto the model family. This is what every real model does, since all models are wrong.

Step 5 — judging an estimator: bias and MSE (D Defs 9.3–9.4, ex. 3).

\[\mathbb{E}(T-\theta)^2 = \underbrace{\operatorname{Var}(T)}_{\text{variance}} + \underbrace{(\mathbb{E}T-\theta)^2}_{\text{bias}^2}\]

Unbiasedness is not required for a good estimator; MSE → 0 already gives consistency (Thm 9.3).

That is the KL projection of the exponential onto the normal family — it gets the first two moments right and the shape (skew, positivity) wrong.

Must-know results

  1. MLE minimises KL from the empirical distribution to the model (equivalently, cross-entropy).
  2. Consistency under identifiability (D Thm 9.1 finite Θ; Thm 9.2 Wald), proved through KL > 0.
  3. Misspecified MLE → KL projection argmin_θ D(p ‖ P_θ).
  4. MSE = variance + bias² (D ex. 3); MSE → 0 ⇒ consistent (Thm 9.3).
  5. Invariance: the MLE of g(θ) is g(θ̂) (e.g. the MLE of σ is √(σ̂²)).
  6. Asymptotic normality and efficiency of the MLE come in Lesson 13 (D Thm 9.8).

Where it shows up

  • Every "negative log-likelihood" loss: cross-entropy (categorical), MSE (Gaussian with fixed variance), Poisson loss (counts), pinball/quantile loss is the exception (not a likelihood unless you choose an asymmetric Laplace model).
  • Language-model pre-training is MLE on next tokens: minimising KL from the data distribution of text to the model.
  • Model misspecification: forward-KL fits are mode-covering (Lesson 3) — why MLE-trained generators can produce blurry averages, and why GANs or other objectives were explored.
  • Expected goals (xG)-type models: logistic regression fit by MLE; calibration follows from the proper-scoring property of log-loss.

Traps

  • MLE can be degenerate: for a Gaussian mixture, putting one component on a single point with σ → 0 sends the likelihood to ∞ (D ch.11, p.101). Regularise or use a local maximum.
  • MLE can overfit with many parameters relative to data; the KL view assumes n large relative to model complexity.
  • Likelihood values are not comparable across models with different data (or different supports / transformations of y).

Lesson 13 — Fisher information and the Cramér–Rao bound ★★★

Fisher information is the curvature of KL divergence between a model and its slightly shifted neighbour: the sharper the log-likelihood peak, the more the data tell you about θ. Its inverse is the best variance any unbiased estimator can achieve, and the MLE reaches it for large samples.

Read

Build it

Step 1 — the score. The slope of the log-likelihood, V = ∂/∂θ ln P(X|θ), says which way the data push θ. At the true θ it averages to zero (D Thm 9.4): data do not systematically push the truth away from itself.

Step 2 — Fisher information = variance of the score = expected curvature.

\[J(\theta) = \mathbb{E}_\theta\Big[\Big(\frac{\partial}{\partial\theta}\ln P(X\mid\theta)\Big)^2\Big] = \mathbb{E}_\theta\Big[-\frac{\partial^2}{\partial\theta^2}\ln P(X\mid\theta)\Big]\]

A sharply curved log-likelihood means a small change in θ makes the data much less likely — the data pin θ down well. For independent observations information adds: Jₙ = nJ₁ (D Thm 9.5), like KL (K Thm 2.1).

Step 3 — the bridge to KL (D Thm 9.6; K eq. 6.4). Expand D(θ ‖ θ+Δθ) around Δθ = 0. The value is 0 and the slope is 0 (minimum of a non-negative function), so the first surviving term is quadratic, and its coefficient is Fisher information:

\[D(\theta\,\|\,\theta+\Delta\theta) \approx \tfrac12\,\Delta\theta^{\top} J(\theta)\,\Delta\theta, \qquad J(\theta,\theta+\Delta\theta) \approx \Delta\theta^{\top} J(\theta)\,\Delta\theta\]

Fisher information is the local metric that KL induces on parameter space. Kullback says it this way (K ch.3 §6, p.63): (dθ)'G(θ)(dθ) is "the basis of the metric of the parameter space".

Step 4 — Cramér–Rao (D Thm 9.7). For an estimator T with mean b(θ), Cauchy–Schwarz on Cov(V, T) = b'(θ) gives:

\[\operatorname{Var}_\theta(T) \ge \frac{[b'(\theta)]^2}{J_n(\theta)}, \qquad \text{unbiased: } \operatorname{Var}_\theta(T) \ge \frac{1}{nJ_1(\theta)}\]

An unbiased estimator attaining the bound is efficient. Equality needs T to be a linear function of the score — which happens exactly in exponential families with T the sufficient statistic (K Thm 5.1 equality conditions).

Step 5 — the MLE is asymptotically efficient (D Thm 9.8). Under regularity conditions,

\[\sqrt n\,(\hat\theta_{ML}-\theta) \;\xrightarrow{d}\; N\big(0,\; J_1(\theta)^{-1}\big)\]

Proof idea (pp.88–89): Taylor-expand the score around θ̂; the numerator is a sum of i.i.d. zero-mean scores (CLT, variance J₁), the denominator → J₁ (LLN). This is where standard errors and Wald confidence intervals come from: θ̂ ± 1.96/√(nJ₁(θ̂)).

Must-know results

  1. Score has mean 0; J = Var(score) = E[−Hessian of log-lik] (D Thm 9.4).
  2. Additivity Jₙ = nJ₁ (D Thm 9.5).
  3. KL ≈ ½ ΔθᵀJΔθ (D Thm 9.6; K ch.2 eq. 6.4): Fisher information is the curvature of KL.
  4. Cramér–Rao bound (D Thm 9.7; matrix version K ch.3 Thm 5.1, Cor. 5.2).
  5. MLE asymptotically normal with variance J⁻¹/n (D Thm 9.8).
  6. Reparametrisation: if η = g(θ), J(η) = J(θ)/g'(θ)² (matrix form G(φ) = U'G(θ)U, K eq. 5.12; D ch.9 ex. 10).
  7. Processing loses Fisher information too: H ≤ G for any statistic, equality iff sufficient (K Thm 5.1).

Where it shows up

  • Standard errors and confidence intervals for any MLE (logistic regression coefficients, Poisson rates) come from the inverse observed Fisher information; statsmodels prints exactly these.
  • Natural gradient descent: step = J⁻¹∇loss, i.e. steepest descent measured in KL rather than Euclidean distance. K-FAC and Shampoo approximate J; Adam's second-moment scaling is a crude diagonal cousin. TRPO/PPO constrain KL between policies, which locally means a Fisher-metric trust region.
  • Elastic Weight Consolidation (continual learning): penalise moving parameters with large Fisher information.
  • Laplace approximation / Bayesian deep learning: posterior ≈ N(θ̂, (nJ)⁻¹) (D Thm 10.3, Lesson 14).
  • Experimental design / A/B test sizing: pick n so that 1/(nJ) gives the precision you need.

Traps

  • Regularity conditions matter: for Uniform(0, θ) the support depends on θ, Fisher information is not defined in the usual way, and the MLE converges at rate 1/n, faster than Cramér–Rao would suggest.
  • Biased estimators can beat 1/Jₙ in MSE (shrinkage, ridge); the bound is for unbiased ones.
  • Observed vs expected information: software often uses the observed Hessian at θ̂; they agree asymptotically.

Lesson 14 — Bayesian inference ★★★

Bayesian inference treats the parameter as uncertain, updates a prior into a posterior with Bayes' rule, and predicts by averaging over that posterior. In log-odds form, the update is exactly Kullback's "information in x". MAP estimation is MLE plus a regulariser, and the Laplace approximation gives you BIC.

Build it

Step 1 — Bayes' rule for parameters (D eq. 10.1).

\[\pi(\theta\mid x_1^n) = \frac{P(x_1^n\mid\theta)\,\pi(\theta)}{\int P(x_1^n\mid\theta')\,\pi(\theta')\,d\theta'}\]

Posterior ∝ likelihood × prior. The denominator — the marginal likelihood or "evidence" — is the hard part.

Step 2 — the information reading (K eq. 2.3). For two hypotheses, log posterior odds = log prior odds + log likelihood ratio. Each observation adds its weight of evidence; the prior is your starting log-odds. Averaged over data and parameter, the expected gain is I(X; Θ), Lindley's information of an experiment (K Example 4.6).

Step 3 — predicting without picking a θ. The Bayesian predictive averages over the posterior (D p.94):

\[P(x_{n+1}\mid x_1^n) = \int P(x_{n+1}\mid\theta)\,\pi(\theta\mid x_1^n)\,d\theta\]

Step 4 — MAP = regularised MLE (D Def. 10.1). Taking −ln of the posterior:

\[\hat\theta_{MAP} = \arg\min_\theta\Big[-\ln P(x_1^n\mid\theta) - \ln\pi(\theta)\Big]\]

A Gaussian prior N(0, τ²) on weights adds ‖w‖²/(2τ²): L2 / weight decay. A Laplace prior adds ‖w‖₁/b: L1 / lasso. A flat prior gives back the MLE (D p.94).

Step 5 — choosing a prior (D p.95). Three criteria: symmetry, invariance, computational convenience.

  • Conjugate priors (D Def. 10.3) keep the posterior in the same family, so updating is just updating hyperparameters. Every exponential family has one.
  • Jeffreys prior (D Def. 10.2) π(θ) ∝ √(det J(θ)): it gives the same inferences in any parametrisation (Thm 10.2), because √det J transforms exactly like a density.

Step 6 — consistency and the Laplace approximation. Almost any prior gives a posterior that concentrates on the truth (Doob, D Thm 10.1). For large n the posterior is ≈ N(θ̂, (nJ₁)⁻¹), and the log evidence is (D Thm 10.3):

\[-\ln P(x_1^n) = -\ln P(x_1^n\mid\hat\theta_{ML}) + \frac{s}{2}\ln\frac{n}{2\pi} + \ln\frac{\sqrt{\det J_1(\hat\theta)}}{\pi(\hat\theta)} + o(1)\]

The first two terms are the BIC: fit + (number of parameters s)/2 · ln n. It is also a code length (Lesson 20).

A Beta(α, β) prior acts like α − 1 and β − 1 imaginary earlier successes and failures in the MAP, and like α and β "pseudo-counts" in the predictive.

Posterior mean = (1·0 + 1·1.5)/2 = 0.75 — the data mean shrunk halfway to the prior because prior and data carry equal precision.

Must-know results

  1. Posterior ∝ likelihood × prior; log-odds update = prior log-odds + evidence (K eq. 2.3).
  2. MAP = penalised MLE; uniform prior ⇒ MAP = MLE (D p.94).
  3. Conjugacy (D Def. 10.3): beta–Bernoulli/binomial, gamma–Poisson (D ex. 2, p.99), normal–normal.
  4. Jeffreys prior ∝ √det J and is parametrisation-invariant (D Def. 10.2, Thm 10.2).
  5. Doob consistency (D Thm 10.1) and the Laplace approximation / BIC (D Thm 10.3).

Where it shows up

  • Regularisation (weight decay, lasso) is MAP; dropout and ensembles are often read as approximate Bayesian averaging.
  • Smoothing counts: Laplace/add-k smoothing for n-gram models and naive Bayes; beta-binomial shrinkage for small-sample rates (conversion rates, a player's shot accuracy after 5 attempts).
  • A/B testing and bandits: Beta posteriors and Thompson sampling.
  • Model selection: BIC and marginal likelihood; hierarchical models for partially pooled estimates (team- and league-level effects).
  • Bayesian deep learning: Laplace approximation around trained weights; variational inference minimises reverse KL to the posterior (Lesson 15).

Traps

  • "Uninformative" priors are parametrisation-dependent: uniform on p is not uniform on logit(p). Jeffreys fixes this.
  • Improper priors (D Example 10.3) are fine only if the posterior is proper.
  • MAP is not invariant under reparametrisation (the mode of a density moves); the full posterior is.

Lesson 15 — EM algorithm and K-means ★★★

When a model has hidden variables, EM alternates two easy steps — guess the hidden variables' posterior (E), then fit parameters as if those guesses were data (M) — and the likelihood can never go down, because the gap it closes is a KL divergence. K-means is EM with hard assignments; the same bound (the ELBO) powers variational inference and VAEs.

Read

  • D ch.11, pp.101–107: set-up of mixture models and Example 11.1 K Gaussian peaks, with the warning that the global maximum is degenerate (σ → 0) (p.101); posterior of the latent variable, eq. (11.2), and the objective Q(θ‖θ') — "a difference of the likelihood and a cross entropy function" (p.102); the EM iteration (11.3) and Thm 11.1 likelihood never decreases, proved with KL ≥ 0 (p.102); Example 11.2 explicit EM updates for Gaussian mixtures, eq. (11.5) (pp.102–103); K-means, eqs (11.6)–(11.7), as the σ → 0 limit (pp.103–104); Thm 11.2 K-means objective never increases (p.104); Example 11.3 Baum–Welch for HMMs with forward–backward probabilities (pp.104–105) ★.
  • D exercises pp.106–107: ex. 1 (mixture of Bernoullis), ex. 2 (twins — a classic EM with incomplete counts).
  • Background: Jensen (D Thm 2.3, Lesson 2) and conditional entropy (Lesson 4).

Build it

Step 1 — the problem. Observed y, hidden z (which cluster a point came from, which HMM state produced a word). If z were known, fitting would be easy (count, average). With z unknown, the likelihood p(y|θ) = Σ_z p(y, z|θ) is a log of a sum — hard to maximise directly.

Step 2 — split the log-likelihood. For any distribution q(z):

\[\ln p(y\mid\theta) = \underbrace{\mathbb{E}_{q}\big[\ln p(y,z\mid\theta)\big] + H(q)}_{\text{ELBO } F(q,\theta)} \;+\; D\big(q(z)\,\big\|\,p(z\mid y,\theta)\big)\]

Check: p(y, z|θ) = p(y|θ)p(z|y, θ); take −ln, average over q, rearrange. Since KL ≥ 0, F is a lower bound on the log-likelihood (the evidence lower bound, ELBO) — the same bound Jensen's inequality gives directly.

Step 3 — E-step. Fix θ = θₙ and choose q to maximise F. The left side ln p(y|θₙ) does not depend on q, so maximising F is the same as minimising the KL term: set q(z) = p(z | y, θₙ) (D eq. 11.2). Now KL = 0 and the bound touches the log-likelihood.

Step 4 — M-step. Fix q and maximise F over θ. H(q) doesn't depend on θ, so maximise the expected complete-data log-likelihood E_q[ln p(y, z | θ)] — D's Q(θₙ‖θ') (p.102). For exponential families this is weighted moment matching (Lesson 11), usually in closed form.

Step 5 — why it never goes down (D Thm 11.1). ln p(y|θₙ₊₁) ≥ F(qₙ, θₙ₊₁) ≥ F(qₙ, θₙ) = ln p(y|θₙ). The first inequality is KL ≥ 0, the second is the M-step, the equality is the E-step. EM climbs to a local maximum (or saddle), not necessarily the global one.

Step 6 — Gaussian mixtures and K-means. E-step: responsibilities r_ik = τ_k N(yᵢ; μ_k, σ_k²) / Σ_j τ_j N(yᵢ; μ_j, σ_j²). M-step (D eq. 11.5): τ_k = average responsibility, μ_k = responsibility-weighted mean, σ_k² = weighted variance. Let all σ → 0 and responsibilities become 0/1 — assign each point to the nearest centre (11.6), then recompute centres as means (11.7). That is K-means, and its within-cluster sum of squares never increases (D Thm 11.2).

Worked examples

Two-component 1-D mixture. Data {1, 2, 3, 7, 8}; σ = 1 fixed; start μ = (2, 6), τ = (½, ½).

Must-know results

  1. Decomposition ln p(y|θ) = ELBO + KL(q ‖ posterior); E-step closes the KL gap, M-step raises the ELBO.
  2. Monotonicity of EM (D Thm 11.1) and of K-means (D Thm 11.2); convergence to local optima only.
  3. GMM updates (D eq. 11.5) and K-means as the hard, σ → 0 limit (D eqs 11.6–11.7).
  4. ★ Baum–Welch = EM for HMMs with forward–backward probabilities (D Example 11.3).

Where it shows up

  • Clustering and segmentation: GMMs and K-means (player-position clustering from tracking data, customer segments, colour quantisation).
  • Missing data and latent classes: EM imputation, latent class models, mixture-of-experts gating.
  • Speech and sequence models: Baum–Welch training of HMMs.
  • Variational inference and VAEs: when the exact posterior p(z|y) is intractable, restrict q to a simple family and maximise the same ELBO jointly over q and θ. The gap is the reverse KL D(q ‖ posterior) — which is why VI is mode-seeking (Lesson 3). The VAE's encoder is q, its KL term is Lesson 9's Gaussian KL.
  • Diffusion models are also trained with an ELBO.

Traps

  • Initialisation matters (K-means++ exists for this reason); run several starts and keep the best likelihood.
  • The number of components K is not chosen by EM; use BIC (Lesson 14), held-out likelihood or domain knowledge.
  • K-means assumes roughly spherical, equal-size clusters; a GMM with full covariances does not.

Lesson 16 — Maximum entropy and minimum discrimination information ★★

If all you know are some averages, the least-committal distribution matching them is the one with maximum entropy — or, relative to a reference distribution, minimum KL from it. The answer is always an exponential family, and fitting it is the same convex problem as maximum likelihood. This is the principle behind logistic regression, Boltzmann distributions and Kullback's whole testing theory.

Read

  • D ch.12, pp.109–115. Skim the Boltzmann H-theorem (pp.109–112) as motivation: entropy of an ideal gas never decreases, and the end state under conservation of particles, momentum and energy is the Gaussian (Maxwell) velocity distribution (p.112). Then: Problem 12.1 (p.112); Thm 12.3 max-ent solution is an exponential family, proved with KL ≥ 0, and Remarks 1–3 (including when no solution exists) (pp.112–113); Thm 12.4 find the multipliers by minimising the convex function ln Z(λ) − λ·α, whose Hessian is a covariance matrix (pp.113–114). Exercises p.115: ex. 3 (uniform on a volume), ex. 4 (every density is max-ent for some constraint), ex. 5 (exponential for a non-negative mean), ex. 7 (max-ent = minimum cross-entropy / MLE within the family).
  • K ch.3 §2, pp.36–43: minimum discrimination information. Minimise I(1:2) over f₁ subject to ∫T(x)f₁(x) = θ (p.37); solution (2.11) f*(x) = e^(τT(x)) f₂(x)/M₂(τ) and minimum value (2.8) I(*:2) = θτ − log M₂(τ) (p.38); Thm 2.1 (p.38); Kullback's note that the approach parallels "maximum-entropy" estimates (Jaynes 1957) (p.37); the table of special values and properties (a)–(d) (p.40); Example 2.1 with Table 2.1 (binomial, p.41).
  • K ch.2 Problem 8.28 (p.34): the discrete max-ent with a fixed mean is p_j = e^(βx_j)/M(β) (cf. Jaynes 1957).

Build it

Step 1 — the problem. You know only that E[Tᵢ(X)] = αᵢ for some statistics (a mean, a second moment, feature averages). Many distributions satisfy this. Which one should you use? Jaynes' answer: the one that assumes nothing else — maximum entropy (D Problem 12.1).

Step 2 — guess the form with Lagrange multipliers. Maximise −∫ρ ln ρ subject to ∫ρ = 1 and ∫ρTᵢ = αᵢ. Setting the derivative of the Lagrangian to zero gives −ln ρ − 1 + λ₀ + ΣλᵢTᵢ = 0, so

\[\rho^*(x) = \exp\Big(\sum_i \lambda_i T_i(x) - \ln Z(\lambda)\Big)\]

An exponential family with exactly the constrained statistics as sufficient statistics (D Thm 12.3, Remark 1).

Step 3 — prove it is the maximum (D Thm 12.3 proof). For any ρ meeting the constraints, −∫ρ ln ρ* depends only on the constrained averages, so it equals H(ρ*). Then H(ρ) = −D(ρ‖ρ*) + H(ρ*) ≤ H(ρ*). Same move as the Gaussian proof in Lesson 9.

Step 4 — Kullback's generalisation: minimum discrimination information. Replace "maximum entropy" by "closest in KL to a reference f₂" (K ch.3 §2). Minimising I(1:2) subject to E₁[T] = θ gives the tilted reference f*(x) = e^(τT(x)) f₂(x)/M₂(τ), where τ is chosen so the constraint holds (θ = d/dτ log M₂(τ)), and the minimum is I(*:2) = θτ − log M₂(τ) (K eqs 2.8–2.11). With a uniform reference, minimising KL = maximising entropy.

Step 5 — computing the multipliers (D Thm 12.4). Minimise L(λ) = ln Z(λ) − λ·α. Its gradient is E_λ[T] − α (zero exactly when the constraints hold), and its Hessian is Cov_λ(T) ≥ 0 — so it is convex with one minimum. This is the negative average log-likelihood of an exponential family when α are sample averages: maximum entropy subject to matching the data's averages = maximum likelihood in the exponential family (D ex. 7). Two views, one optimisation.

Must-know results

  1. Max-ent under moment constraints is an exponential family in those statistics (D Thm 12.3).
  2. Minimum discrimination information: f* = e^(τT)f₂/M₂(τ), I(*:2) = θτ − log M₂(τ) (K ch.3 Thm 2.1).
  3. The dual is convex: minimise ln Z(λ) − λ·α (D Thm 12.4).
  4. Max-ent ⇔ MLE in the exponential family (D ex. 7; Lesson 11 Step 4).
  5. A max-ent solution may not exist (D Remark 3: constraints up to the third moment on ℝ).

Where it shows up

  • Logistic / softmax regression = conditional max-ent ("MaxEnt classifiers" in NLP before deep learning).
  • Energy-based models, Boltzmann machines, statistical physics: p ∝ e^(−E/kT) is max-ent at fixed average energy.
  • Entropy-regularised RL: maximising reward + entropy gives softmax (Boltzmann) policies.
  • Exponential tilting / reweighting: calibrating survey weights or synthetic data to match known margins, importance sampling, and the Chernoff bound all use f* = e^(τT)f/M(τ).
  • Species distribution and ecological modelling (MaxEnt) and default priors when only a few moments are known.

Traps

  • Max-ent is only as good as the constraints you feed it; a missing constraint (e.g. ignoring a known correlation) gives a confidently wrong model.
  • The reference measure matters for continuous variables: max-ent relative to Lebesgue measure is not invariant to reparametrisation; minimum KL relative to a stated reference is.
  • Matching sample moments exactly can overfit; regularised max-ent = MAP in the exponential family.

Part D — Testing and classification (Kullback's core)

Lesson 17 — Hypothesis testing as gathering evidence ★★

A test is a way of turning accumulated evidence (log-likelihood ratios) into a decision. KL sets the price: you need at least a certain amount of information n·I(1:2) to reach given error rates, error probabilities shrink like e^(−n·KL), and twice the estimated minimum discrimination information is a likelihood-ratio statistic that is approximately χ².

Build it

Step 1 — the decision. Split the sample space into E₁ (decide H1) and E₂ (decide H2, the null). Type I error α = P(decide H1 | H2 true); type II error β = P(decide H2 | H1 true) (K p.74).

Step 2 — the best test is a threshold on evidence. Neyman–Pearson: for fixed α, the most powerful region is "log-likelihood ratio log f₁(x)/f₂(x) ≥ c" (K ch.5 Example 3.1, p.87). For n i.i.d. observations, that statistic is a sum of per-observation weights of evidence (Lesson 2).

Step 3 — information you must have (K ch.4 Thm 3.1). A test is a statistic with two values (decide 1 or 2). By data processing (Lesson 5), it cannot carry more discrimination information than the sample. The two-valued statistic's information is the binary KL between (1−β, β) and (α, 1−α):

\[n\,I(1{:}2) \;\ge\; \beta\log\frac{\beta}{1-\alpha} + (1-\beta)\log\frac{1-\beta}{\alpha}\]

This lower-bounds the sample size needed for any test with errors (α, β).

Step 4 — errors decay exponentially at a KL rate (K Thms 3.2–3.3). Fix β. The smallest achievable α satisfies

\[\lim_{n\to\infty}\frac1n\log\frac{1}{\alpha_n^*} = I(1{:}2)\]

and symmetrically for β with I(2:1) (this is Stein's lemma; Kullback credits Chernoff and C. Stein). Each extra observation multiplies the best error by about e^(−KL). So the sample sizes two measurement methods need for the same error are inversely proportional to their KL per observation (K p.77).

Step 5 — the minimum discrimination information statistic (K ch.5 §§1, 3, 4). With composite hypotheses, estimate how far the sample is from the closest member of each: Î(*:H). Reject the null H₂ when Î(*:H₂) − Î(*:H₁) is large. Kullback shows (eq. 4.3) that Î(*:H) = −log λ, the Neyman–Pearson generalised likelihood ratio — so this unifies the classical likelihood-ratio tests. Example 4.2 recovers Student's t-test; Example 1.1 gives the binomial statistic n[p̂ log(p̂/p₂) + q̂ log(q̂/q₂)].

Step 6 — the χ² approximation (K ch.5 §5). Under the null, Wilks: −2 log λ \~ χ² with (k − r) degrees of freedom. Kupperman (K eq. 5.1): 2nÎ \~ χ² with k degrees of freedom when θ̂ is efficient. The reason is Lesson 13: near the null, 2n·KL ≈ n(θ̂−θ)ᵀJ(θ̂−θ), a sum of k squared standard normals.

  4. Î(*:H) = −log(likelihood ratio); t-test, binomial and normal-variance tests are special cases (K ch.5 §4).
  5. 2nÎ and −2 log λ are asymptotically χ² (Wilks; Kupperman, K eq. 5.1).
  6. Classification = assign to the population with smallest Î(*:j) = maximum likelihood/posterior-to-prior ratio (K ch.5 §2).

Where it shows up

  • A/B tests and power analysis: effect size in KL per observation → required sample size; sequential tests (Wald's SPRT) accumulate log-likelihood ratios until a threshold.
  • Likelihood-ratio tests in logistic/Poisson regression (deviance differences ≈ χ²) — statsmodels' LR tests are 2× differences in log-likelihood.
  • Anomaly and drift detection: CUSUM is a running log-likelihood-ratio sum; KL sets how fast it detects a shift.
  • Classifier evaluation: error rates fall exponentially with the number of independent features/observations combined, at a rate set by KL (or Chernoff information when both errors are balanced).

Traps

  • A significant Î or χ² says the data are informative against the null, not that the effect is large or important.
  • The χ² approximation needs regular models and enough data (expected counts not too small); boundary nulls (variance = 0, mixture components) break Wilks.
  • Thm 3.1 gives a necessary amount of information, not a sufficient one.

Lesson 18 — Multinomials and contingency tables: the G-test is 2N × mutual information ★★

For counts, Kullback's statistic 2Σ x log(observed/expected) — the G-statistic — is twice the sample size times a KL divergence. For a two-way table it is 2N times the empirical mutual information between rows and columns, Pearson's χ² is its quadratic approximation, and unlike χ² it splits exactly into additive components.

Build it

Step 1 — goodness of fit for one multinomial (K ch.6 §4.1). Counts x₁, …, x_c from N draws; null H₂ says probabilities p₁, …, p_c. The closest member of the alternative is the empirical distribution xᵢ/N, so the minimum discrimination information statistic is (K eq. 4.3):

\[\hat I(*{:}2;O_N) = \sum_{i=1}^{c} x_i\log\frac{x_i}{Np_i} = N\cdot D(\hat p\,\|\,p)\]

Under the null, 2Î \~ χ² with c−1 degrees of freedom (Lesson 17). This is the G-test, and 2Î = −2 log λ (K p.114).

Step 2 — Pearson's χ² is the quadratic approximation (K eq. 4.5). Using log(a/b) ≈ (a² − b²)/(2ab) for a/b near 1:

\[2\hat I(*{:}2;O_N) \approx \sum_{i=1}^c\frac{(x_i-Np_i)^2}{Np_i} = \chi^2\]

Same reason as Lesson 13: KL is locally quadratic, with Fisher information as the curvature.

Step 3 — independence in a two-way table (K ch.8 §2). Null: pᵢⱼ = pᵢ. · p.ⱼ. The information against it is the KL between the joint and the product of marginals — the mutual information between row and column (Lesson 4). With estimates from the table (K eq. 2.4):

\[\hat I(H_1{:}H_2) = \sum_{i,j} x_{ij}\log\frac{N x_{ij}}{x_{i\cdot}x_{\cdot j}} = N\cdot \hat I(\text{Row};\text{Col}), \qquad G = 2\hat I \sim \chi^2_{(r-1)(c-1)}\]

In entropies (the exercise Kullback sets on p.159): Î/N = Ĥ(Row) + Ĥ(Col) − Ĥ(Row, Col).

Step 4 — additivity (K Table 2.1, p.158). Testing "rows have probabilities pᵢ.", "columns have p.ⱼ" and "rows independent of columns" together, the total 2Î splits exactly into a row component, a column component and the independence component, with degrees of freedom (r−1) + (c−1) + (r−1)(c−1) = rc − 1. Pearson's χ² does not decompose exactly. This is the information analogue of an analysis-of-variance table, and it extends to three-way tables (conditional independence, interactions; K ch.8 §3).

Where it shows up

  • Feature screening: G-tests or MI between a categorical feature and the target; MI = G/(2N) gives an effect size that doesn't grow with N.
  • A/B tests on conversion and categorical drift (category frequencies this month vs last).
  • NLP: Dunning's log-likelihood ratio for collocations and keyword extraction is exactly the 2×2 G-test; pointwise mutual information is its per-cell term.

Lesson 19 — Multivariate normal: LDA, principal components and canonical correlation through information ★★

For Gaussian data, asking "which linear combination y = α'x carries the most discrimination information?" gives you Fisher's linear discriminant (different means), principal components (different covariances), and canonical correlations (dependence between two sets of variables) — each as an eigenvalue problem, with the information split exactly across the components.

Read

  • K ch.9, pp.189–205: §1 the Gaussian I(1:2) and J (eqs 1.1–1.11, p.189–191; see Lesson 9); §2 components of information, eqs (2.1)–(2.7) — information from n observations splits into a means part (x̄) and a covariance part (S) (pp.191–194); §3 canonical form: invariance under non-singular linear maps, (3.1)–(3.2), simultaneous diagonalisation AΣ₁A' = Λ, AΣ₂A' = I, (3.3)–(3.7) (pp.194–195); §4–5 linear discriminant functions with equal covariances, eqs (5.1)–(5.3): α = Σ⁻¹δ is sufficient (p.196), and several groups (5.4)–(5.6) (p.197); §6 principal components, (6.1)–(6.17), including Kullback's warning that the best discriminant "is not necessarily associated with the largest λ" and (6.12) I(1:2) = −½ log|P| (pp.197–200); §7 canonical correlation, (7.4) and (7.16) I(1:2) = −½ log(1−ρ₁²)…(1−ρ_k²), (7.20) (pp.200–204); §8 covariance variates, (8.1)–(8.8) (pp.204–205).
  • K ch.13, pp.342–352 ★: linear discriminants when covariances differ — an iterative solution (2.1)–(2.9) and a worked example from Smith (1947) data (pp.342–347).
  • K ch.12 §§3.3–3.5 (pp.303–304): testing independence and the corresponding discriminant ★.

Build it

Step 1 — project and measure. Any linear combination y = α'x of a Gaussian vector is Gaussian, with means α'μᵢ and variances α'Σᵢα (K eq. 4.2, p.196). So the information it carries is the 1-D Gaussian KL of Lesson 9. Choose α to maximise it. By data processing, no projection can carry more than the full vector (Lesson 5); the question is how close one or a few projections can get.

Step 2 — different means, same covariance: Fisher's LDA (K §5). With δ = μ₁ − μ₂,

\[2I(1{:}2;y) = J(1,2;y) = \frac{(\alpha'\delta)^2}{\alpha'\Sigma\alpha} \;\le\; \delta'\Sigma^{-1}\delta = J(1,2), \qquad \text{equality at } \alpha = \Sigma^{-1}\delta\]

That is Fisher's ratio (between-group separation over within-group spread). The maximising direction loses no information at all — it is a sufficient statistic for discriminating the two populations (K eq. 5.3). With r groups, the directions are the eigenvectors of Σ*α = λΣα and the information splits as J = λ₁ + … + λ_p, so λ₁/Σλ is the share captured by the first discriminant (K eqs 5.4–5.6).

Step 3 — same means, different covariances: principal components (K §6). Now the information in y depends on the variance ratio λ = α'Σ₁α/α'Σ₂α:

\[I(1{:}2;y) = -\tfrac12\log\lambda - \tfrac12 + \tfrac{\lambda}{2}\]

Stationary directions solve Σ₁α = λΣ₂α (K eq. 6.4), and the total splits over the components: I(1:2) = Σ I(1:2; yᵢ) (eq. 6.8). With Σ₂ = independent variables and Σ₁ = the actual correlation structure, these are the principal components of the correlation matrix P, and I(1:2) = −½ log|P| = −½ Σ log λᵢ (eq. 6.12). The most informative component is the one whose λ is farthest from 1 in the sense of g(λ) = −½ log λ − ½ + λ/2 — which can be the smallest-variance component (K p.199).

Step 4 — two sets of variables: canonical correlation (K §7). Split x into x₁ and x₂ and test dependence (H1) against independence (H2: Σ₁₂ = 0). The information is the mutual information between the sets (K eq. 7.4), and it splits over the canonical correlations ρᵢ (eq. 7.16):

\[I(x_1;x_2) = \tfrac12\log\frac{|\Sigma_{11}|\,|\Sigma_{22}|}{|\Sigma|} = -\tfrac12\sum_i\log(1-\rho_i^2)\]

The canonical variate pair (u, v) = (β'x₁, γ'x₂) with the largest ρ carries the most information (eq. 7.20). With one variable in x₂, ρ is the multiple correlation and I = −½ log(1 − R²) (eq. 7.18).

Step 5 — covariates add information even with no mean difference (K §8). If only the last variables differ in mean, including correlated "covariance variates" changes the information from δ₂'Σ₂₂⁻¹δ₂ to δ₂'Σ₂₂.₁⁻¹δ₂, a gain of up to 1/(1 − ρ₁²) (eqs 8.1–8.6). They explain away noise.

Must-know results

  1. Information is invariant under non-singular linear maps; simultaneous diagonalisation splits it into independent components (K §3).
  2. LDA: α = Σ⁻¹δ maximises J and is sufficient; J = δ'Σ⁻¹δ is the squared Mahalanobis distance (K eqs 5.1–5.3).
  3. PCA/variance-ratio components solve Σ₁α = λΣ₂α; information adds over them; the best is not always the largest-variance one (K §6).
  4. Gaussian MI between two sets = −½ Σ log(1 − ρᵢ²) over canonical correlations (K eq. 7.16).
  5. Covariates can add information without a mean difference (K §8).

Where it shows up

  • LDA / QDA classifiers and Fisher's discriminant as a dimensionality-reduction step; Mahalanobis distance for anomaly detection.
  • PCA caveat: unsupervised PCA keeps high-variance directions; for discrimination the informative direction can be low-variance (whitened features, LDA) — a classic reason PCA-then-classify underperforms.
  • CCA for multi-view learning (aligning image and text embeddings, linking two sets of measurements — e.g. physical tests and match performance); deep CCA and CLIP-style objectives maximise cross-view information.
  • Regression adjustment / CUPED in A/B testing: using a pre-period covariate that has no treatment effect but is correlated with the outcome reduces variance — K §8 in modern dress.
  • Gaussian-copula MI estimates use −½ log det of correlation matrices.

Traps

  • All of this assumes (approximately) Gaussian data; with heavy tails or nonlinear structure, linear projections can miss most of the information.
  • Sample covariance matrices in high dimension are noisy; Σ⁻¹ needs shrinkage (Ledoit–Wolf, regularised LDA).
  • Maximising I(1:2), I(2:1) or J gives different discriminants when covariances differ (K ch.13 §1).

Lesson 20 — Kolmogorov complexity and the MDL view of learning ★

The information in a single object is the length of the shortest program that prints it. It is uncomputable, but for data drawn from a computable distribution its average equals Shannon entropy, and it gives the cleanest statement of Occam's razor: the best model is the one that makes the shortest total description of model plus data.

Read

  • D ch.13, pp.117–123: Turing machines (skim pp.117–118); Def. 13.1 Kolmogorov complexity (p.118); universal machines and Thm 13.1 invariance (complexity is machine-independent up to a constant) (p.119); Thm 13.2 C(w) ≤ |w| + c (p.120); Thm 13.3 C is not computable (p.120); Thm 13.4 information-theoretic Gödel theorem (p.120); Thm 13.5 most strings are incompressible (p.121); the incompressibility method, Thms 13.6–13.8 (pp.121–122) ★; Thm 13.9 oscillations (p.122) ★.

Build it

Step 1 — information without probabilities. Shannon's entropy measures a distribution. But "0101…01" (1000 symbols) and a random-looking 1000-bit string seem to carry very different amounts of information on their own. Kolmogorov: the information in w is the length of the shortest program that outputs w (D Def. 13.1). "Print '01' 500 times" is short; for a random string, the best program is essentially "print w" (D Thm 13.2).

Step 2 — it barely depends on the language (D Thm 13.1). Any universal machine can simulate any other with a fixed-length interpreter, so complexities under two universal machines differ by at most a constant. Statements "up to an additive constant" are therefore meaningful.

Step 3 — most things are incompressible (D Thm 13.5). There are fewer than 2^(n−c) programs shorter than n − c bits, so at most a 2^(−c) fraction of n-bit strings can be compressed by c bits. At most 1 in 1024 strings can be shortened by 10 bits. Compression is the exception, and it works only because real data have structure.

Step 4 — you can't compute it (D Thms 13.3–13.4). If a program could compute C(w), a short program could search for the first string with complexity larger than its own length and print it — a contradiction (a Berry-paradox argument). Likewise, no formal system can prove "C(w) > K" for large K. Practical compressors (gzip, LLM + arithmetic coding) give upper bounds only.

Step 5 — the bridge to Shannon (D Thms 14.4–14.5). Use self-delimiting (prefix-free) programs, so Kraft applies. For a computable distribution p, you can describe w by describing p and then w's Shannon–Fano code word:

\[K(w) \;\lesssim\; -\log p(w) + K(p), \qquad H(p) \;\le\; \sum_w p(w)K(w) \;\lesssim\; H(p) + K(p)\]

On average, algorithmic information equals entropy, up to the cost of describing the model. The algorithmic chain rule and symmetric mutual information (Thms 14.6, 14.11) mirror Lesson 4.

Step 6 — minimum description length (MDL). The first inequality in Step 5 is a two-part code: bits for the model + bits for the data given the model. Choose the model that minimises

\[L(\text{model}) + L(\text{data}\mid\text{model}) = L(\text{model}) - \log p_{\text{model}}(\text{data})\]

The second term is the negative log-likelihood (Lesson 12); the first penalises complexity. With L(model) ≈ (k/2) log n for k real parameters, this is the BIC from the Laplace approximation (D Thm 10.3, Lesson 14). Occam's razor, made quantitative.

MDL for polynomial degree. Fitting y = polynomial(x) to 100 points: a degree-1 fit costs about (2/2) log₂ 100 ≈ 6.6 bits for its parameters; a degree-9 fit costs about 33 bits. Pick degree 9 only if it reduces the data's code length (−log-likelihood in bits) by more than the extra ≈ 26 bits.

Must-know results

  1. Kolmogorov complexity = shortest program length; invariant up to a constant (D Def. 13.1, Thm 13.1).
  2. Uncomputable; only upper-bounded by real compressors (D Thms 13.3–13.4).
  3. Almost all strings are incompressible (D Thm 13.5).
  4. Expected prefix complexity ≈ entropy, within the model's description length (D Thms 14.4–14.5).
  5. MDL / two-part codes: total code length = model bits + negative log-likelihood; BIC is its large-sample form.

Where it shows up

  • Model selection and regularisation: MDL, BIC, Bayesian marginal likelihood (Lesson 14) and weight-description-length views of generalisation.
  • Compression-based similarity: normalised compression distance with gzip/zstd for clustering, plagiarism and malware family detection; the "gzip + k-NN" text classifier.
  • LLMs as compressors: a model's total log-loss on a dataset plus the model's size is a two-part code length — the MDL lens on scaling and on why memorisation differs from generalisation.
  • Randomness testing and anomaly detection: sudden changes in compressibility of a log or sensor stream flag structure changes.
  • Solomonoff induction (prior 2^(−K)) is the idealised Bayesian learner behind "simpler hypotheses are more probable"; D ch.15 links it to Bayesian consistency.

Traps

  • "Up to a constant" can hide a large constant; for short strings, complexity statements are nearly meaningless.
  • A good compression ratio is an upper bound on complexity, never a measurement of it.
  • MDL depends on how you encode the model; different encodings give different penalties (BIC, AIC-like, normalised maximum likelihood).
